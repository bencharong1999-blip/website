# ชุดส่งต่อสกิล v2 — บ่าวเบน อยากเป็นไทบ้าน

ชื่อช่องปัจจุบัน: **บ่าวเบน อยากเป็นไทบ้าน** ตามคำสั่งวันที่ 4 พฤศจิกายน 2026
ชื่อ “ไทบ้านคุณภาพ” ในต้นฉบับบางไฟล์เป็นประวัติ ไม่ใช่ชื่อปัจจุบัน
รหัสทางเทคนิค `thai-work-kit` คงไว้เพื่อรักษาเส้นทางและไฟล์อ้างอิง

## สำหรับ Claude Code / Codex และโปรเจกต์อื่น

รวบรวมเมื่อ 6 พฤศจิกายน 2026 จากสกิลที่เข้าถึงได้ในแชตนี้

## สิ่งที่ได้

- `skills/` คำสั่ง SKILL.md ต้นฉบับ 38 ตัว จัดชื่อกลุ่มให้อ่านง่าย เป็นสำเนาสำหรับอ่าน ไม่ใช่โครงติดตั้งที่รักษาลิงก์ครบ
- `sources/` คำสั่งและเอกสารประกอบที่อ่านได้ โดยเก็บเส้นทางแหล่งข้อมูลไว้
- `plugins/thai-work-kit/` ต้นฉบับปลั๊กอินส่วนข้อความเวอร์ชัน 0.7.2 รวม 9 สกิล เอกสารกลาง สคริปต์ตัดต่อ ซับ และงานวิดีโอ รักษาโครงสร้างปลั๊กอินไว้
- `inventory.json` รายชื่อสกิล แหล่งที่มา และรายการไฟล์ที่ระบบอ่านไม่ได้ รายการความล้มเหลวนี้เป็นผลจากช่องทาง skills.read; ไฟล์ของบ่าวเบน อยากเป็นไทบ้านจำนวนมากกู้มาได้ภายหลังผ่านต้นฉบับปลั๊กอิน

## นำไปใช้

1. แตก ZIP นี้ไว้ในโปรเจกต์หรือคลังกลางของคุณ
2. เปิด Claude Code หรือ Codex ที่โฟลเดอร์โปรเจกต์
3. ส่งคำสั่งด้านล่าง โดยแก้เส้นทางให้ตรงกับเครื่องของคุณ

> อ่าน README-TH.md และ inventory.json ในโฟลเดอร์ skill-export นี้ แล้วเลือกสกิลที่ตรงกับงานของโปรเจกต์ สำหรับงานบ่าวเบน อยากเป็นไทบ้านให้อ่าน plugins/thai-work-kit/README.md และเลือก SKILL.md จาก plugins/thai-work-kit/skills/ โดยรักษาโฟลเดอร์ references และ scripts ที่เชื่อมโยงกัน ตรวจเครื่องมือและ dependencies ก่อนใช้งาน ถ้าจะติดตั้งเป็นสกิลของ Claude Code หรือ Codex ให้ตรวจรูปแบบติดตั้งของเวอร์ชันที่ใช้อยู่และรักษาไฟล์อ้างอิงทั้งหมด บอกให้ชัดว่าส่วนไหนพร้อมใช้และส่วนไหนยังขาด อย่าอ้างว่าเชื่อมบัญชีหรือทดสอบสคริปต์แล้วจากการมีไฟล์เพียงอย่างเดียว

สามารถอ่านสกิลจากไฟล์โดยตรงได้ก่อนติดตั้ง อย่าย้ายเฉพาะ SKILL.md ของบ่าวเบน อยากเป็นไทบ้าน เพราะใช้ ../../references และสคริปต์ร่วมกัน

## ขอบเขตและสิ่งที่ยังขาด

- เป็นการส่งออกสิ่งที่มองเห็นในแชตนี้ ไม่ใช่การกู้ทุกแชตเก่า ทุกไฟล์ที่เคยแนบ หรือซอร์สโค้ดของทุกโปรเจกต์
- ยังไม่ได้ส่งออกเนื้อหา Notion, Google Drive, ฟุตเทจ หรือ repository ของโปรเจกต์ต่าง ๆ
- สกิล Notion, Google Drive, Sites, Browser และ Pets ต้องมีเครื่องมือหรือบัญชีเชื่อมต่อของระบบปลายทาง การคัดลอกคำสั่งไม่ได้คัดลอก MCP server, สิทธิ์เข้าถึง หรือบัญชี
- diagram-design มี SKILL.md และเอกสารประกอบบางส่วน แต่เอกสาร แม่แบบ และสคริปต์หลายรายการระบบไม่อนุญาตให้อ่านผ่านช่องทางนี้ จึงยังไม่ครบแพ็กเกจ
- บ่าวเบน อยากเป็นไทบ้านดึงไฟล์ข้อความได้ทั้งหมด 153 ไฟล์จากรายการต้นฉบับ 155 ไฟล์ ไม่รวมไฟล์ไบนารี 2 ไฟล์ ดูรายการใน inventory.json อาจต้องเติมฟอนต์หรือ asset ที่ขาดก่อนรันงานที่ใช้ไฟล์เหล่านั้น
- ไม่รวม credentials หรือการเชื่อมต่อบัญชี และยังไม่ได้รันสคริปต์วิดีโอทั้งหมดในเครื่องปลายทาง
- เก็บ LICENSE และข้อมูล upstream ที่อ่านได้ไว้แล้ว ให้ตรวจเงื่อนไขของต้นฉบับก่อนแจกจ่ายหรือใช้ในคอร์สเชิงพาณิชย์
