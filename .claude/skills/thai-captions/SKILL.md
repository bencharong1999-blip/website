## การเรียกใช้จากแชต

เริ่มงานที่ต้องใช้บริบทข้ามแชตจาก [ข้อมูลกลางและทะเบียนทักษะ](../../references/central-knowledge.md) ใช้เฉพาะส่วนที่เกี่ยวข้องและผลอ่านล่าสุดในงานนี้ ไม่ให้ผู้ใช้ทวนบรีฟเดิมเมื่อค้นพบแล้ว

ใช้ [วิธีทำงานจากแชตและเลือกเครื่องมือ](../../references/chat-execution.md) ก่อนเริ่ม เลือกสกิลนี้จากเจตนาของคำขอได้โดยไม่ต้องให้ผู้ใช้จำชื่อสกิล ทำงานที่ได้รับอนุญาตจนส่งผลที่ตรวจได้ ไม่หยุดเพียงเสนอแผนหรือบอกว่าทำได้ เมื่อมีลิงก์วิดีโอให้ใช้ `clip-breakdown` ตรวจการเข้าถึงก่อนขอให้แนบไฟล์ใหม่ งานอ่านหรือแกะคลิปไม่ต้องถามความยาวและพล็อตของงานผลิตชุดใหม่

ก่อนเริ่มงาน ใช้ [กติกาทำงานของเบน](../../references/ben-working-standard.md): ถามความยาวและพล็อตสำหรับชุดใหม่ ส่งตัวอย่างก่อนผลิตเต็ม เก็บบทพากย์และไฟล์เสียงแยก ใช้ผลเดิมซ้ำและบันทึกบทเรียน คำตอบที่เบนให้แล้วในงานเดียวกันไม่ต้องถามซ้ำ


# ถอดเสียงและจัดซับไทยจากเสียงจริง

ใช้คู่กับ `ffmpeg-skill` สำหรับเรนเดอร์ อ่าน [บริบทโครงการ](../../references/thaiban-project.md) เมื่อจำเป็นต้องอ้างแผนหรือชื่อเฉพาะ

## เริ่มใช้งาน

หากยังไม่มีไฟล์สคริปต์ในเครื่อง ให้อ่าน [การเปิด runtime จากแพ็กเกจเดิม](../../references/video-runtime-setup.md) ก่อน

แทน `<skill-dir>` ด้วยตำแหน่งสกิลจริง ไม่ใช่พาธจากแชตเก่า ใช้ Python ของ venv ที่มี dependencies แล้ว เครื่องมือประมวลผลเสียงในเครื่อง น้ำหนักโมเดลอาจดาวน์โหลดครั้งแรก และไม่ได้รวมอยู่ในปลั๊กอิน

```sh
python <skill-dir>/scripts/transcribe_thai.py --check
```

หากขาด dependencies ให้ใช้สคริปต์ที่แนบสร้าง venv ในพื้นที่เขียนได้ โดยรักษา venv และต้นฉบับเดิม:

```sh
python <skill-dir>/scripts/setup.py --venv /workspace/thaiban-asr-venv
```

อย่าอ้างว่าทุกแชตติดตั้งแล้ว ตรวจสภาพแวดล้อมก่อน หากไม่มีพื้นที่รันคำสั่ง ให้แจ้งข้อจำกัด ไม่ส่งพรอมต์แทนแล้วอ้างว่าได้ไฟล์ซับ

## ขั้นตอน

1. ตรวจไฟล์และภาษา ใช้ `--language th` สำหรับเสียงไทยตามคำขอ ชื่อแบรนด์ใช้ initial prompt ได้ แต่ไม่ถือข้อความ prompt เป็นคำพูดที่ยืนยันแล้ว
2. ถ้าคลิปต้องตัดช่วงเวลา ให้ตัดให้เสร็จก่อนแล้วถอดเสียงจากไฟล์ฉบับนั้น หรือถอดเสียงเพื่อหาจุดตัดและถอดใหม่หลังตัด ห้ามนำซับเวลาเก่าไปเผาทับคลิปที่ถูกตัดแล้วโดยไม่ปรับเวลา
3. เรียกสคริปต์พร้อม out-dir ใหม่และ model-cache ที่เขียนได้:

```sh
<venv-python> <skill-dir>/scripts/transcribe_thai.py edited.mp4 --out-dir captions-C001 --language th --model base --model-cache /workspace/thaiban-models
```

4. อ่าน `report.json`, `transcript.json`, `captions.srt`, `captions.ass` และ `words.json` ที่ได้ ตรวจชื่อเฉพาะ คำอีสาน ราคา และจังหวะ โมเดล base เป็นจุดเริ่มต้น หากเสียงไทยหรืออีสานไม่แม่น ให้ลองโมเดลหลายภาษา `small` หรือใหญ่ขึ้นเมื่อทรัพยากรพอ ไม่ใช้รุ่น `.en` กับภาษาไทย
5. การตัดบรรทัดใช้ PyThaiNLP รักษาคำกับเครื่องหมายไทย ไม่รับประกันความถูกต้องทุกคำ หากมี overflow ให้ย่อความกว้างของแบบอักษร/ปรับขนาดหรือแบ่ง cue โดยยึดเวลาคำจริง ห้ามลบคำจากซับเงียบ ๆ เพื่อให้พอดี
6. เผาซับผ่าน `../ffmpeg-skill/scripts/caption.py INPUT --ass captions.ass` โดยอ้างตำแหน่งสกิลข้างเคียงจริง วิธี ASS รักษาบรรทัดไทยที่จัดแล้ว ไม่ให้ตัวเรนเดอร์แบ่งกลางคำซ้ำ ใช้ฟอนต์ไทยที่มี เช่น Noto Sans Thai ปรับตำแหน่งตามเฟรมจริง ไม่มี face detection ในชุดนี้

## ซับเคลื่อนไหว

สคริปต์ส่งทั้ง SRT สำหรับแก้ต่อและ ASS สำหรับเรนเดอร์ เพิ่ม `--style fade` หรือ `--style pop` ตอนถอดเสียง/จัดซับเพื่อเลือกแอนิเมชัน ชุดนี้มี plain, fade และ pop ไม่ใช่ 24 สไตล์ของผู้ขายรายอื่น ASS เริ่มที่กรอบออกแบบ 1080×1920; งานแนวนอนให้ตั้ง `--frame-width`/`--frame-height` และตรวจขนาดฟอนต์/ขอบตามเฟรมจริง

ตรวจรูปทรงสระ/วรรณยุกต์จริง ถ้าต้องการ karaoke ตรงคำ ให้ตรวจตัวเลือก `--transcribe` และข้อมูลที่ตัวเรนเดอร์รองรับก่อน ห้ามแบ่งเวลาเท่ากันแล้วอ้างว่าตรงเสียงรายคำ คำที่ได้จาก ASR อาจเป็นกลุ่มคำ ไม่ใช่คำไทยที่ตัดสมบูรณ์

## ตัดคำเติมเสียง

รายการคำใน [thai-fillers.txt](references/thai-fillers.txt) เป็นเพียงจุดเริ่มต้น ใช้ `words.json` กับ `silence.py INPUT --filler --words ... --filler-words ... --margin 0 --list --json` เพื่อดูจุดที่เสนอ ก่อนตัดจริงเมื่อคำขอครอบคลุมการตัด คง `--margin 0` สำหรับรอบตัด filler โดยเฉพาะ เพราะช่วงคำสั้นอาจสั้นกว่าระยะเผื่อช่วงเงียบปกติ และตัวตัด filler มี padding ของตัวเองอยู่แล้ว อ่าน keep/removed จริง ไม่ถือจำนวนคำที่พบว่าเท่ากับจำนวนคำที่ตัดสำเร็จ ห้ามใช้ transcript อย่างเดียวเดาเวลา หากโมเดลไม่ถอดคำเอ่อ/อ่า จะตรวจคำเหล่านั้นไม่ได้ ต้องฟังช่วงที่สงสัยหรือแก้เวลาจากหลักฐาน

ไม่ตัด “ครับ”, “ค่ะ”, “อ้าว” หรือประโยคซ้ำโดยอัตโนมัติ เพราะอาจมีความหมาย ตรวจจุดตัดและเว้นระยะขอบไม่ให้กินคำข้างเคียง เก็บไฟล์ต้นฉบับและรายการตัดไว้เสมอ

## ส่งมอบ

อ่าน [คู่มือ iPhone และ CapCut](../../references/iphone-quickstart.md) ก่อนส่งขั้นตอนแก้ซับให้เบน แยก SRT/ASS ที่แก้ไขได้จาก MP4 ที่เผาซับแล้ว ถ้าขอแก้ซับเองให้ส่ง clean MP4 ที่ยังไม่มีซับเผาและ SRT ของฉบับตัดเดียวกันด้วย

อย่าอ้างว่านำเข้า SRT ตรงใน CapCut iPhone ได้ หรือแก้คำในซับเผา MP4 เป็นข้อความได้ เอกสาร CapCut รองรับนำเข้า SRT บน Desktop/Web ส่วนทางมือถือให้เลือกส่งคำแก้กลับมาเรนเดอร์ใหม่ หรือสร้างข้อความ/Auto Captions บน clean MP4 ตามความสามารถของบัญชีและแอปจริง

ส่งไฟล์ซับที่แก้ต่อได้และไฟล์วิดีโอเฉพาะที่สร้างสำเร็จ บอกว่าตรวจเสียง/ภาพส่วนใดแล้ว ถ้าเป็นเพียงซับ อย่าเรียกว่าวิดีโอตัดเสร็จ ส่งต่องานตรวจโพสต์ให้ `quality-check` ไม่เผยแพร่เอง

แหล่งเครื่องมือ: [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp) สคริปต์เชื่อมต่อในชุดนี้เขียนเพิ่มเฉพาะงานบ่าวเบน อยากเป็นไทบ้าน ไม่ได้บรรจุโมเดลหรือโค้ดจาก PAN X BOXY
