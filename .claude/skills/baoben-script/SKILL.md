# บทและโครงเรื่อง — บ่าวเบน อยากเป็นไทบ้าน

แทน write-and-revise + clip-breakdown + "ตัดต่อเล่าเรื่อง" ของชุดเดิม

## ตัวตนช่อง

- ชื่อ: **บ่าวเบน อยากเป็นไทบ้าน** · สโลแกน: **เริ่มใหม่ ไปด้วยกัน**
- เรื่องจริงของเบน: เมื่อก่อนเที่ยว เมา ได้เงินมาก็ใช้หมด ไม่มีเงินเก็บ → เกิดอุบัติเหตุ (รายละเอียดเบนจะเล่าเอง) → เริ่มคิดเปลี่ยนชีวิตมาเป็นไทบ้าน
- น้ำเสียง: จริงใจ เหมือนเล่าให้เพื่อนฟัง ภาษาของเบน มีคำอีสานได้ ไม่ใช้ภาษาขายของลอย ๆ
- เพื่อน/พี่ ๆ ในสังคมเดิมเป็นคนดี — ห้ามเขียนให้เป็นผู้ถูกกล่าวโทษ

## อินพุตที่ต้องมี (ถามครั้งเดียวถ้ายังไม่มีในแดชบอร์ด/คลังแผนเดิม)

ความยาว · พล็อต/อารมณ์ · เรื่องจริงที่จะเล่า · ฟุตเทจ/เสียงที่มี · แพลตฟอร์ม (ค่าเริ่ม 9:16)

## ขั้นตอน

1. อ่านแดชบอร์ดงาน Notion (ดูสกิล `baoben-start`) และบรีฟ/บทเดิมในคลังแผนเดิมเฉพาะหัวข้อ — ใช้ฮุก คำปิด และบทที่เบนอนุมัติแล้วต่อ ไม่เริ่มใหม่
2. วางโครง: **ฮุก → บริบท → ลงมือ → จุดเปลี่ยน → เหตุผล → ผลลัพธ์ → ชวนติดตาม** ตามเหตุจริงเท่านั้น
   - ฮุกอิงเรื่องจริง (เสนอได้ ≤ 3 แบบให้เลือก ไม่ร่างบทเต็มหลายชุด)
   - ทุกตอนต้องมีเนื้อหาจบในตัว ไม่กั๊กเรื่อง; คำปิดบอกว่า EP ถัดไปจะได้ดูอะไร
   - ถ้าเนื้อหาสั้นกว่าเป้า ห้ามยืดด้วยการแต่ง ให้ถามเหตุการณ์จริงเพิ่ม
3. ส่งให้เบนเป็นสองส่วนแยกกัน:
   - **บทอ่าน** (ให้เบนอัดเองด้วยแอปบันทึกเสียง iPhone; พูดผิดให้เริ่มเฉพาะประโยคนั้น)
   - **ตารางภาพ / paper edit**: ช่วง · คำพูด · ภาพ/ไฟล์ต้นทาง+เวลา · ข้อความบนจอ · เหตุผล
4. ระบุชัดว่าเป็น "ร่าง ยังไม่อนุมัติ" จนเบนยืนยัน แล้วเก็บบทอนุมัติเป็นไฟล์ (Drive/GitHub) และลิงก์ในทะเบียนคลิปแดชบอร์ด

## แกะคลิปตัวอย่าง (clip breakdown)

1. บันทึกขอบเขตที่ดูจริง: metadata, ซับอัตโนมัติ, จำนวนภาพที่ดู (ไม่อ้างว่าดูทุกเฟรม/ฟังครบ)
2. สรุปเป็น "สิ่งที่เรียนรู้ → ปรับใช้กับบ่าวเบนอย่างไร" ไม่คัดบท ภาพ เพลง หรือประวัติของเขามาใช้ ไม่รับรองยอดวิว
3. บันทึกบทเรียนลงส่วน 7.8 ของคลังแผนเดิม (ทะเบียนทักษะยังอยู่ที่นั่น) (ชื่อทักษะ → ปัญหาที่แก้ → แหล่ง/วันที่ → ผลทดลอง → ข้อจำกัด)

## เล่าเรื่อง ไม่ใช่ตอบคำถาม (เบนตีกลับ EP3 — 6 พ.ย. 2026)

EP3 ตัดจากคลิปที่เบนตอบคำถาม 5 ข้อ (ทำอะไรหาเงิน / รายได้ / ยากตรงไหน / สนุกตรงไหน / เป้าหมาย) ต่อกันพร้อมป้ายหัวข้อ เบนบอกว่า "สะเปะสะปะ เหมือนตอบคำถาม ฉันอยากเล่าเรื่องไทบ้าน" → ไม่ผ่าน ยกเลิกทั้งตอน

- ห้ามวางโครงตอนเป็นรายการคำถาม–คำตอบ และห้ามใช้ป้ายหัวข้อแบบ "รายได้ตอนนี้ / ยากตรงไหน" คั่นเรื่อง
- บรีฟให้เบนต้องเป็น **เรื่องที่มีเหตุการณ์เดินไปข้างหน้า** (เช่น หนึ่งวัน/หนึ่งงานตั้งแต่เริ่มจนจบ มีคน สถานที่ ปัญหาที่เจอ แล้วจบยังไง) ไม่ใช่ชุดคำถามให้นั่งตอบหน้ากล้อง
- ภาพกิจกรรมเป็นตัวเล่าเรื่องหลัก เสียงเบนเล่าทับเหมือนเล่าให้เพื่อนฟัง หน้าเบนพูดกับกล้องใช้เฉพาะช่วงที่ต้องการอารมณ์/ความรู้สึก
- ก่อนส่งบรีฟ ถามตัวเองว่า: ถ้าตัดป้ายหัวข้อออก คนดูยังรู้ไหมว่าเรื่องเริ่มตรงไหน เกิดอะไรขึ้น และจบยังไง — ถ้าไม่รู้ แปลว่ายังเป็นการตอบคำถาม

## ข้อห้าม

- ไม่แต่งรายละเอียดอุบัติเหตุ ปี สาเหตุ การบาดเจ็บ หรือรายได้ที่ยังไม่เกิด
- คำกล่าวอ้างสินค้า (Affiliate) ต้องมาจากการใช้จริงของเบน แยกข้อมูลผู้ขายออกจากประสบการณ์เบน
