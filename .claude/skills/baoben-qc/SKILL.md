# ตรวจคุณภาพและส่งมอบ — บ่าวเบน อยากเป็นไทบ้าน

แทน quality-check + กติกาส่งมอบของชุดเดิม

## 1. ตรวจไฟล์

```bash
python3 .claude/skills/baoben-qc/scripts/qc.py <ไฟล์.mp4> [--expect-fps 60] [--json report.json]
```

สคริปต์ตรวจ: ขนาด 1080×1920 · fps · H.264/AAC · ความดัง (LUFS / true peak / LRA) · ภาพดำ · ถอดรหัสทั้งไฟล์ไม่มี error → ผล PASS / WARN / FAIL ต่อข้อ

จากนั้น:
- ดึงภาพตัวอย่างจุดสำคัญ (ฮุก ประโยคหลัก คำปิด) ด้วย `baoben-footage/scripts/contact_sheet.py` แล้ว **เปิดดูจริง**: สระ/วรรณยุกต์ไทย ข้อความล้น บังหน้า ระยะขอบ UI
- เทียบข้อความบนจอกับบทที่อนุมัติ และข้อเท็จจริงกับเรื่องที่เบนเล่า (ไม่มีรายละเอียดที่แต่งเพิ่ม)
- คำเตือน "ไม่มี subtitle track" เป็นเรื่องปกติเมื่อเผาข้อความในภาพและส่ง SRT แยก

## 2. รายงานต่อเบน (แยกให้ชัด)

- **สร้างไฟล์แล้ว**: ชื่อ เวอร์ชัน ความยาว
- **ตรวจอะไรแล้ว**: ผลสคริปต์ + จำนวนภาพที่ดู
- **ยังตรวจไม่ได้**: เช่น ยังไม่ได้ฟังทุกคำ, ยังไม่ได้ทดสอบ UI บนแพลตฟอร์มจริง
- **โพสต์แล้วหรือยัง**: ผู้ช่วยไม่โพสต์เองถ้าไม่ได้สั่ง

## 3. ส่งมอบเข้า Google Drive

1. ฉบับเผยแพร่ไปไว้หมวด `05_ไฟล์พร้อมเผยแพร่` (folder `15wkh7PzfEGcdz2YrhTDmaRXRfbldLNQ0`) ไฟล์โปรเจกต์/ไฟล์สนับสนุนอยู่ในโฟลเดอร์ EP ของมัน
2. ชื่อไฟล์: `YYYY-MM-DD_ชนิดวันที่_เรื่อง_เวอร์ชัน.นามสกุล` หรือแบบที่ใช้อยู่ เช่น `00_EP01_คลิปเต็ม_พร้อมเผยแพร่_1080p.mp4`
3. ฉบับแก้: อัปเดตไฟล์เดิมเพื่อ **คงชื่อ/ID/ลิงก์หลัก** ถ้าเครื่องมือรองรับ
4. Drive connector อาจปฏิเสธไฟล์ > 100 MiB → แบ่ง ZIP เป็นส่วน ๆ พร้อม manifest + SHA-256
5. **อ่านกลับ** metadata (ชื่อ ID MIME ขนาด parent) และรายการในโฟลเดอร์ปลายทางว่าตรง แล้วจึงแจ้งเสร็จพร้อมเส้นทางที่เบนกดได้
6. อัปเดตหน้าแผน Notion (ส่วนงานผลิตล่าสุด + ทะเบียนคลิปส่วน 9) ให้ตรงกับไฟล์จริง

ห้ามลบไฟล์หรือเปลี่ยนสิทธิ์แชร์โดยไม่ได้รับคำสั่ง
