# ตรวจฟุตเทจ — บ่าวเบน อยากเป็นไทบ้าน

แทน watch ของชุดเดิม ต้องมี Bash + ffmpeg/ffprobe + Python (Pillow) ถ้าไม่มี ให้บอกเบนและทำได้แค่อ่าน metadata จาก Drive

## ขั้นตอน

1. **รับไฟล์**: ดาวน์โหลดจาก Drive (หมวด 02 ฟุตเทจ / 03 เสียง) ลงโฟลเดอร์งานใหม่ ห้ามแก้หรือเขียนทับต้นฉบับ
2. **ตรวจซ้ำ**: `sha256sum` ทุกไฟล์ ไฟล์ที่แฮชตรงกันทุกไบต์คือสำเนาซ้ำ — รายงานก่อน ลบเฉพาะเมื่อเบนสั่ง
3. **metadata**: `ffprobe -v error -show_format -show_streams -of json <ไฟล์>` → ความยาว ขนาด fps ทิศทาง (rotation) มีเสียงไหม
4. **contact sheet**:
   ```bash
   python3 .claude/skills/baoben-footage/scripts/contact_sheet.py <วิดีโอ> -n 12 -o sheet.jpg
   # หรือกำหนดช่วง: --start 5 --end 40
   ```
   ได้ภาพตาราง + ไฟล์ JSON เวลาของแต่ละภาพ เปิดดูภาพด้วย Read ก่อนอ้างถึงเนื้อหาภาพ
5. **แยกช็อตทั้งชุด (ทดสอบแล้ว 5 พ.ย. 2026)** — ใช้เมื่อมีหลายไฟล์ เช่น ฟุตเทจเก่า 72 ไฟล์:
   ```bash
   pip install "scenedetect[opencv-headless]==0.6.4"   # ครั้งแรกของแต่ละเครื่อง (PySceneDetect, BSD-3)
   python3 .claude/skills/baoben-footage/scripts/scenes.py <ไฟล์...> -o shots.json --sheet shots.jpg
   ```
   ได้ทุกช็อต: เริ่ม–จบ · ความสว่าง · ความคม + ป้าย `dark` / `blurry` และภาพรวมกลางช็อตทุกช็อตในภาพเดียว เปิด `shots.jpg` ด้วย Read ก่อนเลือก
   ป้ายเป็นตัวช่วยคัดกรอง ไม่ใช่คำตัดสิน (ภาพกลางคืนที่ตั้งใจมืดยังใช้ได้) ทดสอบกับวิดีโอสังเคราะห์ 3 ช็อต: แยกครบ 3 และติดป้ายมืด/เบลอถูกช็อต ยังไม่ได้รันกับฟุตเทจเบน
6. **เสียง**: วัดระดับด้วย `ffmpeg -i <ไฟล์> -af ebur128=peak=true -f null -` (ดูบรรทัด Summary) ใช้ช่วยค้นเท่านั้น
7. **รายการช็อต** ส่งเบน: ไฟล์ · ช่วงเวลา · สิ่งที่เห็น · ใช้ได้กับช่วงไหนของบท · ปัญหา (มืด/สั่น/เบลอ) · สิ่งที่ต้องถ่ายเพิ่ม
8. ระบุขอบเขตเสมอ เช่น "ดูภาพตัวอย่าง 12 จุดในช่วง 0–40 วิ ยังไม่ได้ฟังเสียงทั้งไฟล์"

## หมายเหตุ

- ไฟล์จาก iPhone มักเป็น HEVC/HDR และอาจมี rotation — ตรวจก่อนตัด
- ASR ช่วยหาเวลาคำพูดได้ แต่เวลาช่วงเงียบ/เสียงเบาคลาดได้ ให้เทียบกับระดับสัญญาณ ไม่ตัดตาม timestamp อย่างเดียว
