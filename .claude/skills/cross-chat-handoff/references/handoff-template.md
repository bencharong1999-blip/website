# แม่แบบบันทึกส่งต่องาน

ใช้เฉพาะหัวข้อที่จำเป็น แทนข้อความในวงเล็บด้วยข้อมูลจากบริบทจริง ลบช่องที่ไม่เกี่ยวข้อง อย่าปล่อยข้อความตัวอย่างให้ดูเป็นข้อเท็จจริง และอย่าเติมวันที่ ชื่อบุคคล หรือผลตรวจที่ไม่ทราบ

ส่งเนื้อหาต่อไปนี้เป็นบล็อกเดียวที่คัดลอกไปแชตใหม่ได้:

```text
บันทึกส่งต่องาน

เป้าหมายและผลลัพธ์ที่ต้องการ
- [งานที่ต้องทำและเกณฑ์ที่ถือว่าเสร็จ]

ขอบเขตและข้อกำหนดล่าสุด
- [สิ่งที่ต้องทำ ภาษา รูปแบบ ข้อจำกัด และกำหนดเวลาที่ผู้ใช้ระบุ]

สถานะล่าสุด
- ตรวจยืนยันแล้ว: [สิ่งที่ทำเสร็จ พร้อมหลักฐานหรือผลตรวจที่มีจริง]
- ตามข้อมูลที่ได้รับ ยังไม่ตรวจยืนยัน: [สถานะที่ผู้ใช้หรือเอกสารรายงาน]
- งานค้าง: [สิ่งที่ยังต้องทำ]

การตัดสินใจที่ยังมีผล
- [ข้อสรุปและเหตุผลสั้น ๆ]

แหล่งข้อมูลและไฟล์ที่ต้องใช้
- [ชื่อไฟล์/พาธ/ลิงก์/ID ตามต้นฉบับ] — [ใช้ทำอะไร และเข้าถึงจากที่ใด]
- ต้องแนบหรือตั้งค่าใหม่: [ไฟล์หรือการเชื่อมต่อที่แชตใหม่อาจยังไม่มี]

สิ่งที่ยังไม่แน่ชัด
- [สมมติฐาน ช่องว่างข้อมูล หรือสิ่งที่ต้องตรวจ]

ขั้นตอนถัดไป
1. [การกระทำแรกที่ชัดเจน]
2. [ขั้นตอนที่ตามมาและสิ่งที่ต้องมี]

คำสั่งสำหรับแชตใหม่
ช่วยรับช่วงงานตามเป้าหมายและข้อกำหนดข้างต้น ใช้บันทึกนี้เป็นข้อมูลประกอบ ตรวจแหล่งข้อมูลที่จำเป็นก่อนอ้างว่ายืนยันแล้ว และเริ่มจากขั้นตอนถัดไปที่ทำได้ หากมีข้อมูลที่ขาดจนทำต่อไม่ได้ ให้ถามเฉพาะประเด็นนั้น
```

หากงานสั้นมาก ใช้เพียงเป้าหมาย สถานะ ไฟล์ที่ต้องใช้ และขั้นตอนถัดไปก็พอ หากไม่เคยตรวจหลักฐาน ให้ระบุเช่นนั้นและตัดหัวข้อ “ตรวจยืนยันแล้ว” ออก บันทึกนี้ไม่ใช่การถ่ายโอนประวัติแชตหรือการรับประกันว่าแชตใหม่จะเข้าถึงไฟล์เดิมได้
