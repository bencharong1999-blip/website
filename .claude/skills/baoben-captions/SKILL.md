# ซับไทย — บ่าวเบน อยากเป็นไทบ้าน

แทน thai-captions ของชุดเดิม

## ขั้นตอน

1. ใช้เสียงจากฉบับตัดจริง (ไม่ใช่ต้นฉบับยาว) ถ้าการตัดเปลี่ยน ต้องทำเวลาซับใหม่
2. ASR (เลือกตามที่มี): `faster-whisper` หรือ `openai-whisper` รุ่น small/medium ภาษา `th`
   - ไม่มีในเครื่อง → `pip install faster-whisper` (ฟรี รันในเครื่อง) ห้ามส่งเสียงเบนไปเว็บสาธารณะ
   - โมเดลต้องโหลดจาก huggingface.co ครั้งแรก — **เครื่อง Claude Code บนคลาวด์ของเบนตอนนี้ถูกนโยบายเครือข่ายบล็อก huggingface.co** (ตรวจ 5 พ.ย. 2026) ถ้าโหลดไม่ได้ ให้บอกเบนเพิ่ม huggingface.co ใน Allowed domains ของ environment หรือให้ Codex/เครื่องอื่นถอด แล้วใช้ `voice.py report` (สกิล baoben-edit) หาเวลาช่วงพูดแทนไปก่อน
   - ภาษาไทยแม่นขึ้น: รุ่นที่ฝึกภาษาไทย เช่น Thonburian Whisper (`biodatlab/whisper-th-medium-combined`, แปลงเป็น CTranslate2 ก่อนใช้กับ faster-whisper) — ยังไม่ได้ทดสอบ เพราะโหลดโมเดลไม่ได้
   - เสียงเบามาก → ทำสำเนาปรับระดับก่อนถอด เก็บต้นฉบับ
   - ถ้า VAD ข้ามคำ → ถอดเฉพาะช่วงนั้นซ้ำแบบปิด VAD
3. ข้อความบนจอใช้ **บทที่เบนอนุมัติ** เป็นหลัก ASR ใช้หาเวลาและจับคำที่เบนพูดต่างจากบท
4. ตรวจด้วยตา: ชื่อเฉพาะ (บ่าวเบน, ไทบ้าน, Codex อ่าน "โคเด็ก"), คำปฏิเสธ ("ไม่ได้", "ไม่ใช่"), ตัวเลข ราคา คำอีสาน — คำไม่ชัดให้ทำเครื่องหมายถามเบน ไม่เดา
5. แบ่งบรรทัด ≤ ~20 ตัวอักษรไทย/บรรทัด ≤ 2 บรรทัด ตัดตามวลี ไม่ตัดกลางคำ
6. เขียน `captions.json` → สร้างทั้ง `.srt` (ส่งแยก) และ `.ass` (สไตล์ขาว-เหลือง ตัวหนา ขอบดำ) จากแหล่งเดียวกัน
7. รายงาน: "ซับเป็นร่างจากบท + ASR ตรวจเวลาแล้ว ยังไม่ได้ฟังทุกคำด้วยมนุษย์" ถ้าเป็นจริง

## หมายเหตุ CapCut

SRT นำเข้าได้บน CapCut Desktop/Web แต่แอปมือถือนำเข้าตรงไม่ได้ — ถ้าเบนจะแก้เองบน iPhone ให้ใช้ไฟล์ clean + Auto Captions

## ถอดเสียงไทยโดยไม่ต้องใช้ huggingface.co (ทดสอบจริง 5 พ.ย. 2026)

เครื่อง Claude Code ถูกบล็อก huggingface.co แต่ดาวน์โหลดจาก GitHub ได้ → ใช้ Whisper small (int8) ของ sherpa-onnx จาก GitHub releases
```bash
pip install sherpa-onnx numpy
python3 .claude/skills/baoben-captions/scripts/asr.py setup --models <โฟลเดอร์โมเดล>      # ~640 MB ครั้งเดียวต่อเครื่อง
python3 .claude/skills/baoben-captions/scripts/asr.py run --models <โฟลเดอร์โมเดล> <ไฟล์> -o asr.json --srt asr.srt
```
- ผลทดสอบ: IMG_3640 (เบนพูดปิดท้าย 109 วิ) ถอดได้อ่านรู้เรื่องกว่าผล faster-whisper เดิม เร็วประมาณเท่าเวลาจริงบน CPU
- ยังเป็น ASR ดิบ: ชื่อคน คำอีสาน ตัวเลข และพยางค์ท้าย ("ครับ") อาจผิด ต้องตรวจก่อนใช้เป็นซับหรือคำอ้าง
- ดึงไฟล์จาก Drive: เครื่องมือ Drive ดาวน์โหลดได้ไม่เกิน 256 MB ต่อไฟล์ (ผลถูกบันทึกเป็นไฟล์ JSON base64 แล้วถอดด้วย python) ไฟล์ใหญ่กว่านี้ต้องให้เบนส่งสำเนาเล็ก
