## ขั้นตอนเมื่อเบนส่งไฟล์มา

1. **รับ:** เบนส่งทางแชต Codex → อัปต้นฉบับ **ไม่บีบอัด ไม่ตัด** เข้า `00_รับเข้า` · เบนอัปเข้า Drive เอง (ที่ไหนก็ได้) → ย้ายเข้า `00_รับเข้า` (ถ้าเครื่องมือย้ายไม่ได้ ให้จดตำแหน่ง+ID ในทะเบียน แล้วบอกเบนในแถวสมุดส่งงานว่าต้องย้ายเอง)
2. **ตรวจ:** SHA-256 · ffprobe (ความยาว ขนาด fps codec rotation มีเสียงไหม) · ซ้ำกับไฟล์ที่มีแล้ว → `_ซ้ำ`
3. **จัด:** ย้ายเข้า `01_วิดีโอ` / `02_เสียงเล่า` / `03_รูป` · **ไม่เปลี่ยนชื่อไฟล์ต้นฉบับ** (เช่น `IMG_4001.MOV` คงเดิม เพื่อเทียบกับมือถือเบนได้) · ใช้ชื่อกลาง `name` = ชื่อไฟล์ไม่มีนามสกุล
4. **ทำไฟล์เล็ก** ตาม `handoff-json.md` → `_proxy` + `intake.json`
5. **ทะเบียน:** เพิ่มแถวใน `ทะเบียนไฟล์.md`
6. **แจ้ง:** แถวในสมุดส่งงาน Notion (ส่วน 8) — จำนวนไฟล์ อะไรขาด อะไรเสีย ID ของ intake.json
