# EP03 — ปรับหน้าเบน (รีทัชเฉพาะผิวหน้า) + ตัวอย่างภาพกิจกรรมแทรก v01

ทำโดยจอห์นสอง (Claude Code) 6 พ.ย. 2026 · สถานะ: **ตัวอย่าง รอเบนตรวจลุค ยังไม่ผ่านตรวจไขว้**

## สิ่งที่ตรวจแล้วว่าทำได้จริง (ทดสอบในเครื่องรอบนี้)

- รีทัชเฉพาะใบหน้าทำได้ด้วย `scripts/retouch.py` (OpenCV YuNet หาใบหน้า + มาสก์ผิว) ไม่ใช่เบลอทั้งภาพ
  - หาใบหน้าเจอ p001 791/822 เฟรม, p004 1037/1068 เฟรม (เฟรมที่ไม่เจอคือจอท้าย CapCut ~2 วิ) · ช่วงตัวอย่าง 389/389 เฟรม
  - มาสก์ = วงรีใบหน้า × สีผิว (YCrCb) − ตา − ปาก → ขอบนุ่ม · ดูมาสก์แล้ว ไม่โดนผม ตา พื้นหลัง
  - ทำให้ผิวนุ่มเฉพาะความถี่ต่ำ (คำนวณบนหน้าย่อขนาดคงที่ 160 px แล้วบวกกลับเฉพาะส่วนต่าง) → รูขุมขน หนวด คิ้ว ขนตา คงรายละเอียดเดิม และได้ลุคเท่ากันทั้ง proxy 540p และต้นฉบับ 1080p
  - หน้าสว่างขึ้น 4% + อุ่นขึ้นเล็กน้อย เฉพาะในมาสก์ · ทั้งภาพปรับเบา ๆ `eq=gamma=1.04:contrast=1.02:saturation=1.05`
- สีถูกช่วง: ถอด/เข้ารหัส BT.709 เอง — ผ่านสคริปต์แบบไม่ปรับ เทียบกับ ffmpeg ตรง PSNR 42 dB (เจอบั๊กเกรดก่อนแปลงสีทำภาพซีด แก้แล้ว)
- ไฟล์ค่า `ep03-retouch.json` เรนเดอร์ซ้ำได้ภาพเหมือนตัวอย่างทุกพิกเซล (PSNR = inf)
- ความเร็ว 1080×1920 60fps ≈ 3.3 เฟรม/วิ บน 4 คอร์ (4 วิ ใช้ 73 วิ) → ช่วงเบนพูดในฉบับตัด ~80 วิ ≈ 25–30 นาที

## ยังไม่ได้ทำ / ข้อจำกัด

- ไม่ใช่ Beauty ของ CapCut: ไม่ปรับรูปหน้า ไม่ลบสิว/ตำหนิเฉพาะจุด ไม่แต่งหน้า (ปาก ตา) — ตั้งใจให้เป็นธรรมชาติ
- ตัวอย่างทำจาก proxy 540p 15fps (ดึงจาก Drive ได้ ≈ 5 MB/ไฟล์) → ภาพในตัวอย่างนุ่มกว่าของจริงเพราะขยายจาก 540p ฉบับจริงต้องเรนเดอร์จากต้นฉบับ 1080p
- ยังไม่ได้ลองกับ p002 (30fps) p003 p005 · หน้าหันข้าง/ก้มมากอาจหลุดการจับหน้า → สคริปต์ค้างตำแหน่งเดิม 0.5 วิแล้วค่อยปิดผล (ไม่กระตุก) แต่ยังไม่ได้ตรวจทุกช่วง
- ภาพกิจกรรม: ดึงได้เฉพาะไฟล์ ≤ 5 MB = IMG_3601 (1.27 วิ) และ IMG_3605 (1.09 วิ) รถมอเตอร์ไซค์ทางไปนา (IMG_3583 3.2 วิ เป็นภาพหลุดกล้อง ใช้ไม่ได้) · คลิปกิจกรรมอื่น 30–990 MB ยังไม่มี proxy

## วิธีเรนเดอร์จริง (จอห์นหนึ่ง)

```bash
pip install opencv-python-headless numpy          # ทดสอบกับ 5.0.0.93
# โมเดล YuNet อยู่ใน .claude/skills/baoben-edit/models/ แล้ว (MIT)
python3 .claude/skills/baoben-edit/scripts/retouch.py IMG_3683_p001.mp4 p001_rt.mp4 \
  --params .claude/baoben/ep03-retouch.json [--ss 1.0 --t 25.9] \
  [--mask-debug p001_mask.mp4] --report p001_rt.json
```

- ใช้ไฟล์แบ่ง 1080p ต้นฉบับ (ID ใน intake.json) **ไม่ใช่ proxy** · ทำเฉพาะช็อตเบนพูด ภาพกิจกรรมไม่ต้องผ่านสคริปต์
- ผลเป็น H.264 crf 18 BT.709 คง fps ต้นทาง (p002 = 30fps) แล้วค่อยเข้า render.py ตามปกติ — **อย่าใส่ฟิลเตอร์หน้า/เกรดซ้ำใน render.py** (ห้ามซ้อนฟิลเตอร์)
- ตรวจ `report.json`: `face_frames / frames` ควรใกล้ 100% (ยกเว้นจอท้าย) · ถ้าช่วงไหนหน้าหลุด ดู `--mask-debug`
- ปรับลุคแก้ JSON ที่เดียว: นุ่มขึ้น/น้อยลง `smooth.strength` (0.4–0.8) · สว่างหน้า `face_lift.brightness` (0.02–0.06; เกิน 0.06 เริ่มขาวลอย) · ปิดผลชั่วคราว `--off` · ไม่เกรดทั้งภาพ `--no-grade`
- ขอ proxy ภาพกิจกรรม (คลิป 00_รับเข้า ที่ไม่ใช่ IMG_3683) ≤ 5 MB + contact sheet เพื่อให้จอห์นสองเลือกภาพแทรกฉบับเต็ม
