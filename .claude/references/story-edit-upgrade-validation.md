# ตรวจการเพิ่มทักษะตัดต่อ — 0.7.1

เพิ่มกระบวนการตัดต่อเล่าเรื่อง แม่แบบ beat/timeline และ edit-decision log เชื่อมเข้า ffmpeg-skill, write-and-revise, watch, quality-check และ clip-breakdown โดยเก็บคำแก้ผู้ใช้ในกติกากลาง

ตรวจ JSON/YAML, ชื่อสกิล, ลิงก์อ้างอิงภายใน และ manifest คงค่าเดิมยกเว้น version ไม่มีการแก้สคริปต์ตัดต่อเดิม ไม่ต้องรันทดสอบ FFmpeg/ASR ซ้ำสำหรับการแก้คู่มือนี้ ไม่มีผลตัดต่อจริงของเบนรอบนี้ และยังไม่ทดสอบ J/L-cut หรือคุณภาพก่อน/หลัง ความสามารถที่บันทึกใหม่เป็นกระบวนการและเกณฑ์ตัดสินใจที่ต้องนำไปตรวจในงานจริง
