# ตัดต่อให้คนเข้าใจและอยากตามเรื่อง — สำหรับงานบ่าวเบน

เป้าหมายผู้ใช้: เพิ่มฝีมือการตัดต่อจากคลิปอ้างอิง แล้วนำมาใช้กับงานจริงของเรา ไม่หยุดที่การแกะคลิปหรือเปิดลิงก์ การอัปเดตนี้เพิ่มกระบวนการและเกณฑ์ตัดสินใจให้สกิลเดิม ไม่เปลี่ยนน้ำหนักโมเดล ไม่รับรองว่าเก่งกว่าผู้สร้างต้นทางหรือยอดวิวดีขึ้นแน่นอน

## อะไรเรียนจากคลิป อะไรเป็นข้อเสนอของเรา

อ่าน [หลักฐานคลิปบ้านสามชั้น](clip-storytelling-case.md) สำหรับแหล่งและข้อจำกัด สิ่งที่ได้จากซับคือเดิมพันที่ชัด การเล่าเหตุผล การเปลี่ยนทิศทางด้วยอุปสรรค และการบอกผลกระทบก่อนรายละเอียด ส่วน J/L cut, sound bridge, การเลือกขนาดช็อตและการวางข้อความด้านล่างเป็นเครื่องมือตัดต่อที่เราเสนอเพื่อใช้หลักนั้น ไม่ใช่สิ่งที่ยืนยันว่าเห็นหรือได้ยินจากต้นฉบับ ไม่วิเคราะห์เพลง ทรานซิชันหรือความถี่คัตของตัวอย่างจาก ASR

## 1. หาเรื่องและสิ่งที่คนดูจะได้รับ

เขียนหนึ่งประโยค: เบนกำลังทำอะไร → มีข้อจำกัดจริงอะไร → ตัดสินใจอย่างไร → ผลที่คนดูจะได้เห็นในตอนนี้คืออะไร ใช้เวลา เงิน ความพยายาม ความคาดหวัง หรือความเสี่ยงเมื่อมีหลักฐาน ไม่ต้องสร้างดราม่า; เรื่องธรรมดาอาจมีความสงสัยหรือการเปลี่ยนแปลงเล็ก ๆ เป็นแกนได้

ตั้งคำถามหลักหนึ่งข้อและกำหนดว่าภาพ/คำพูดใดตอบคำถามนั้น ถ้าไม่มีคำตอบจริงให้ปรับฮุกให้ซื่อตรงกับสิ่งที่มี หลีกเลี่ยงอินโทรยาวก่อนคนรู้ว่าจะดูอะไร

## 2. คัดฟุตเทจตามหน้าที่

ใช้ watch และเสียงจริง/ซับที่มี เก็บรหัส Cxxx และ source in/out โดยแยกเวลาที่ตรวจแล้วจากเวลาวางแผน

| หน้าที่ | คัดอะไร | เหตุผลที่จะเก็บ |
| --- | --- | --- |
| ตั้งต้น | สถานที่ เป้าหมาย สิ่งที่กำลังทำ | ให้รู้ว่าใครทำอะไรที่ไหน |
| เดิมพัน/ข้อจำกัด | เวลา งบ สภาพจริง หรือความตั้งใจที่พูดไว้ | ให้เข้าใจว่าทำไมเรื่องนี้สำคัญ |
| ลงมือ | มือทำงาน รายละเอียด ขั้นที่คนดูต้องเข้าใจ | พาเรื่องไปข้างหน้า |
| ปัญหา | สิ่งที่ไม่เป็นไปตามคาดพร้อมบริบท | สร้างคำถามใหม่จากเหตุจริง |
| ตัดสินใจ | เหตุผลที่เลือกแก้แบบนี้ | เผยวิธีคิดของเบน |
| พิสูจน์ | ก่อน/หลัง ผลทดสอบ ชิ้นงาน หรือรายละเอียดที่ยืนยันคำพูด | ให้เห็นแทนเชื่อจากคำกล่าวอ้าง |
| ปฏิกิริยา | คำพูด สีหน้า หรือความเงียบที่มีบริบท | ให้พื้นที่ความรู้สึก ไม่ตัดทุกช่องว่าง |
| ผลลัพธ์ | สิ่งที่ทำสำเร็จ/ไม่สำเร็จ และบทเรียน | ตอบสิ่งที่เปิดเรื่อง |

ภาพแทรกที่ไม่พิสูจน์หรืออธิบายอะไรใช้เฉพาะเมื่อมีหน้าที่ด้านบรรยากาศชัดเจน ภาพ stock/ภาพสร้างต้องไม่ทำให้เข้าใจว่าเป็นเหตุการณ์จริงของเบน

## 3. ทำ paper edit ก่อนแต่งภาพ

เรียงคำพูดและภาพหลักเป็น ฮุก → บริบทเท่าที่จำเป็น → การลงมือ → จุดติดขัด → ทางเลือกและเหตุผล → ผลลัพธ์ ไม่บังคับทุกเรื่องเข้าทุกช่องหรือเรียงตามนี้หากทำให้เหตุการณ์บิดเบือน ใช้ผลลัพธ์บางส่วนเปิดได้ แต่ต้องให้คนเข้าใจลำดับเวลาจริง

- เก็บประโยคที่เพิ่มข้อมูล พาเรื่องเดิน หรือทำให้เข้าใจความรู้สึก ตัดคำอธิบายซ้ำที่ไม่เพิ่มสาร
- เปลี่ยนจากบอกขั้นตอนลอย ๆ เป็นเชื่อมเหตุผล: ทำสิ่งนี้เพราะต้องการอะไร โดยใช้ข้อมูลที่เจ้าตัวบอกจริง
- ใช้ “แต่/เพราะ/จึง” เมื่อมีความสัมพันธ์จริง ไม่เติมคำเพื่อทำให้ทุกช่วงดูมีปัญหา
- การย้ายคำพูดต้องไม่เปลี่ยนว่าใครพูด เรื่องใด เกิดก่อนหลังอย่างไร หรือทำให้การคาดเดากลายเป็นผลยืนยัน
- ตรวจรายละเอียดชื่อ ตัวเลข คำปฏิเสธและเงื่อนไข ไม่ตัดเพื่อให้ประโยคแรงขึ้นจนผิดความหมาย

ตารางทำงาน: beat ID | หน้าที่ในเรื่อง | source file/in/out | คำพูด | ภาพหลักฐาน | เสียง | ข้อความบนจอ | เหตุผลตัด/ย้าย/เก็บ | สิ่งที่ยังต้องตรวจ ใช้ [แม่แบบ](story-edit-template.json) เก็บเป็นแผนแก้ต่อได้ ไม่ใช่ schema ของ render.py หรือโปรเจกต์ CapCut

## 4. แปลงเป็นการตัดต่อภาพและเสียง

| สิ่งที่ต้องการเล่า | การตัดสินใจที่ใช้ได้ | วิธีลงมือ/ข้อควรตรวจ |
| --- | --- | --- |
| เปิดให้รู้เรื่องเร็ว | เลือกประโยคและภาพที่บอกเป้าหมาย/ผลกระทบทันที | cut.py/join.py ใช้ช่วงจริง อย่าตัดจนขาดบริบท |
| อธิบายเหตุผล | ให้เสียงเล่าต่อขณะเห็นภาพที่พิสูจน์เหตุผล | broll.py รักษาเสียงพูด ตรวจภาพตรงคำและสิทธิ์ |
| เปลี่ยนเรื่องอย่างต่อเนื่อง | ทดลอง J-cut ให้เสียงเหตุการณ์ถัดไปเริ่มก่อนภาพ หรือ L-cut ให้เสียงเดิมต่อหลังเปลี่ยนภาพ | ต้องมีเสียงจริงแยกและตั้ง trim/offset จริง ตรวจ --help ของตัวที่ใช้ หากไม่รองรับใช้ FFmpeg filtergraph ที่ทดสอบแล้ว ไม่เดา flag |
| ให้คนเข้าใจสถานที่/การกระทำ | เริ่มช็อตกว้างพอรู้บริบทแล้วเลือกภาพกลาง/ใกล้ที่มีข้อมูลเพิ่ม | fit/crop ตามเฟรมจริง ไม่ซูมทุกประโยคหรือครอปสิ่งสำคัญ |
| เน้นจุดเปลี่ยน | เปลี่ยนภาพเมื่อข้อมูล/อารมณ์เปลี่ยน เว้นช่องหรือเบาเพลงเมื่อเหมาะ | อย่าเติมเสียงตกใจหรือจัดดนตรีเพื่อบิดความรู้สึกจริง |
| ทำรายละเอียดให้อ่านง่าย | เน้นเฉพาะตัวเลข คำสำคัญ หรือแผนภาพที่ช่วยเข้าใจ | graphics/Remotion เมื่อจำเป็น แยกข้อความเน้นจากซับเต็มประโยค |
| จบให้อิ่ม | ให้เห็นผลและคำตอบก่อนคำชวนติดตาม | ไม่ใช้ cliffhanger กลบการที่ตอนนี้ไม่มีสาระจบ |

จังหวะคัตตามหน่วยความคิด การกระทำและอารมณ์ ไม่มีสูตรเปลี่ยนช็อตทุกกี่วินาทีที่ใช้กับทุกเรื่อง ให้ภาพที่ต้องอ่าน/สังเกตมีเวลาพอ และรักษาช่วงพักที่ทำให้เชื่อมกับคนเล่า เพลงอยู่ใต้เสียงพูด ฟังเทียบก่อน/หลัง ใช้เสียงหน้างานช่วยเล่าสถานที่เมื่อมีจริงและมีคุณภาพ ไม่ทำเสียงที่หายไปให้เหมือนกู้กลับได้

## 5. ปรับใช้กับงานเรา

รักษาภาษาและบุคลิกเบน เล่าเหมือนคุยกับเพื่อน ไม่ยกภาษาขายบ้านหรืองบหลักล้านมาใช้ลอย ๆ ตัวอย่างต่อไปนี้เป็นเพียงแนวคิด ต้องเติมด้วยเหตุการณ์จริงก่อนเขียนบท:

- ชีวิตประจำวัน/งานลงมือทำ: สิ่งที่ตั้งใจทำ → จุดที่ยากจริง → เหตุผลที่เลือกแก้ → ภาพการลงมือ → ผลที่เกิด
- ทดลองอุปกรณ์: คำถามที่อยากรู้ → วิธีลองที่เห็นได้ → เงื่อนไข/ข้อจำกัด → ผลจริง → เหมาะกับใครตามหลักฐาน ไม่มีผลทดลองให้ทำแผนถ่ายแทนคำรีวิว
- Vlog: เป้าหมายของวัน → เหตุการณ์ที่ทำให้แผนเปลี่ยนถ้ามี → การเลือกของเบน → ความรู้สึก/สิ่งที่ได้กลับมา ไม่บังคับมีดราม่าหรือบทเรียนยิ่งใหญ่

ใช้ความยาวและแนวที่เบนเลือกสำหรับงานนั้น ไม่เอาความยาวคลิปอ้างอิงมาแทนบรีฟ งานผลิตใหม่ยังส่งตัวอย่างตามกติกาเดิม ไม่ต้องขออนุมัติเพียงเพื่อบันทึกคู่มือทักษะนี้

## 6. ตรวจและเรียนจากฉบับตัด

ตรวจตามลำดับ: เรื่องก่อน → ภาพหลักฐาน → ความต่อเนื่อง → เสียง → ซับ/กราฟิก → ส่งออก

- ฮุก: เปิดประเด็นตรงกับเรื่องและได้คำตอบในตอนหรือไม่?
- ความเข้าใจ: คนที่ไม่รู้เบื้องหลังตามเหตุผลแต่ละจุดได้หรือไม่? ระบุช่วงที่ข้อมูลขาดแทนใส่ภาพสวยกลบ
- หลักฐาน: ข้อกล่าวอ้างสำคัญมีภาพ/เสียง/ข้อมูลรองรับหรือยัง?
- จังหวะ: ช่วงใดซ้ำ ช่วงใดเร็วเกินอ่าน ช่วงใดควรเก็บความเงียบ? แก้ตามตำแหน่งจริง
- ความซื่อตรง: การสลับคำพูด ภาพแทน และก่อน/หลังทำให้เข้าใจเหตุการณ์ผิดหรือไม่?
- ผลลัพธ์: ตอนนี้มีสิ่งที่คนดูได้รับจริงหรือใช้ตอนต่อทดแทนคำตอบ?

เก็บ edit-decision log ก่อน→หลัง→เหตุผล→ผลตรวจ/คำแก้ของเบน ต่อคลิป เก็บ timeline และสินทรัพย์เพื่อแก้เฉพาะจุด ไม่เรนเดอร์ทุกอย่างใหม่โดยไม่มีเหตุ หลังเผยแพร่ให้ใช้ summarize-evidence เปรียบเทียบข้อมูล retention/ดูจบ/คอมเมนต์ที่มีจริงในช่วงอายุโพสต์ใกล้กัน ทดลองเปลี่ยนเรื่องสำคัญทีละอย่าง อย่าอ้างเหตุและผลหรือคะแนน “เก่งขึ้น” จากยอดวิวคลิปเดียว

## ระดับความพร้อม

คู่มือนี้เพิ่มวิธีทำงานและเชื่อมสกิลคัดช็อต เขียน ตัด และตรวจเข้าด้วยกัน สคริปต์เดิมยังใช้ตาม help/ผลทดสอบเดิม รอบนี้ไม่ได้ตัดต่อฟุตเทจเบนหรือทดสอบ J/L-cut จริง จึงต้องตรวจตัวอย่างจากงานจริงก่อนยืนยันคุณภาพหรือความสามารถเชิงปฏิบัติส่วนที่เพิ่ม
