# เหตุผลการคัดเลือกสำหรับไทบ้านคุณภาพ

## เพิ่มกรอบตัดสินใจในสกิลเดิม (0.4.2)

ผู้ใช้ส่ง [AI Boardroom Starter Kit โดย Uncle AI Engineer](https://drive.google.com/file/d/1_4HdUHfGDqWEz5VrtieZcZuAmSDRNNvR/view) มาให้พิจารณา อ่านไฟล์แล้วเลือกเพียงแนวคิดพิจารณาหลายมุม ตรวจข้อโต้แย้ง และทดลองจากหลักฐาน เขียนใหม่ใน [decision-review](../skills/plan-work/references/decision-review.md) สำหรับ `plan-work` เพื่อใช้กับการเลือกช่องทาง อุปกรณ์ และรูปแบบคอนเทนต์ ไม่เพิ่มจำนวนสกิล และไม่ติดตั้งหรือรันทีม adviser จากชุดต้นฉบับ

ปรับให้ใช้ข้อมูลจริงของโครงการ ไม่กำหนดเปอร์เซ็นต์ความมั่นใจขึ้นเอง ไม่ยกคะแนนจากหลายมุมเป็นหลักฐานหลายแหล่ง และไม่บังคับกระบวนการประชุมกับงานประจำ ไม่มีการอ้างว่าเอกสารตัวอย่างคือผลประชุมหรือคำตัดสินของเบน

ปรับตามคำขอผู้ใช้และ [ไทบ้านคุณภาพ — แผนหลักและงานทั้งหมด](https://app.notion.com/p/40b52d4a2f43818d8e8ccf778995100f) ที่อ่านเมื่อ 1 พฤศจิกายน 2026 หน้าแผนเป็นแหล่งงานหลัก ส่วนเอกสารนี้อธิบายเหตุผลเลือกสกิล ไม่ใช้แทนสถานะล่าสุดใน Notion

| งานที่แผนต้องใช้ | สกิลที่คงไว้และปรับ |
| --- | --- |
| งานวันนี้ไม่เกิน 3 งานที่พร้อมทำ / แผนคลิปทดลอง | `plan-work` ใช้สถานะจากหน้าเดิม รักษารหัสงานและคลิป |
| คลิปเปิดตัว คลิปสั้น และ Vlog จากเหตุการณ์จริง | `write-and-revise` เพิ่มช็อต คำพากย์ และแนวทางตัดต่อ โดยไม่รับรอง MP4 ที่ยังไม่ทำ |
| ผลคลิป ต้นทุน และคอมมิชชัน | `summarize-evidence` แยกข้อมูลขาดออกจากศูนย์ และแยกยอดรอยืนยันกับเงินรับจริง |
| เบนตรวจภาพ เสียง ข้อความ และข้อมูลก่อนโพสต์ | `quality-check` ตรวจเท่าที่เข้าถึงจริง พร้อมระบุสิ่งที่ยังตรวจไม่ได้ |
| ทำงานต่อข้ามแชตและกลับมาหน้าแผนเดิม | `cross-chat-handoff` เก็บลิงก์หลัก รหัสงาน และไฟล์ที่ต้องใช้ |

ตัดสกิลโปสเตอร์ ค้นกระแส และตีโจทย์แยกออก เพราะยังไม่ใช่กระบวนการหลักในแผน คำถามที่จำเป็นยังถามได้ในสกิลที่เกี่ยวข้อง ไม่เพิ่มสกิลดีไซน์ โค้ด เครื่องมือ scraping เซิร์ฟเวอร์ หรือความจำ runtime เพียงเพื่อให้มีจำนวนมาก

แนวทางเกลาภาษาไทยในสกิลเขียนศึกษาแนวคิดจาก [Humanizer](https://github.com/blader/humanizer) และแนวทางตรวจด้วยหลักฐานจาก [ECC](https://github.com/affaan-m/ECC) เป็นคำแนะนำที่เขียนใหม่ ไม่ใช่ติดตั้งโปรแกรมหรือ hooks ของต้นฉบับ บทความ GitHub ที่ผู้ใช้ส่งเป็นจุดเริ่มค้น ส่วนการคัดเลือกครั้งนี้ให้แผนงานจริงของโครงการเป็นเกณฑ์หลัก

การปรับแพ็กเกจครั้งนี้ไม่เปลี่ยนหน้าแผนใน Notion ไม่เปลี่ยนบัญชีหรือภาพแบรนด์ ไม่สมัคร Affiliate และไม่เผยแพร่คลิป


## เพิ่มตามคำขอตัดต่อวิดีโอ (0.4.0)

เพิ่ม `ffmpeg-skill` พร้อมสคริปต์จริงจาก kajisho5/ffmpeg-skill และ `thai-captions` พร้อมตัวเชื่อม faster-whisper/PyThaiNLP สองสกิลนี้ใช้ลงมือทำงานที่สกิลเขียนเตรียมไว้ ไม่ดึงสกิลโปสเตอร์ ค้นกระแส หรือชุดโค้ดทั่วไปกลับเข้ามา อ่าน commit ใบอนุญาต และผลทดสอบใน [บันทึกวิดีโอ](video-validation.md)


## เพิ่มเฉพาะความสามารถที่ใช้ได้และเก็บตัวเลือก — 0.5.0

เพิ่ม `watch` จาก [bradautomates/claude-video](https://github.com/bradautomates/claude-video/tree/03ceb42f7fa2c4439aca01752118044baabffb8f/skills/watch) ภายใต้ MIT เพื่อสร้างหลักฐานภาพพร้อมเวลาก่อนเขียนลำดับตัดต่อ โดยเก็บ scripts ต้นทางและเพิ่มทางเรียก local-file-only ไม่เปิด cloud หรือเพิ่ม ASR อีกชุด ใช้ `thai-captions` เดิมเมื่อจำเป็นต้องรู้คำพูด ไม่มี hook หรือตัวติดตั้งอัตโนมัติเพิ่ม

งานปรับเสียงใช้ `ffmpeg-skill/scripts/audio.py` ที่มีอยู่แล้ว เพิ่มคู่มือทดสอบเบา ๆ ไม่ติดตั้งสกิลเสียงซ้ำ อ่าน [ผลตรวจ](skill-selection-validation.md) และ [คลังสำรอง](future-skill-library.md) ซึ่งแยกตัวที่ยังไม่ติดตั้งและตัวที่ซ้ำกับชุดเดิม ชื่อสกิลในคลังสำรองไม่ใช่รายการ active

ตรวจ README/ต้นทาง Watch และ README/LICENSE/CREDITS ของ Thai Claude Skills แล้ว สกิล reel-editor-th ต้องใช้ Mac Apple Silicon จึงพักไว้ Hook/caption/calendar หลายตัวซ้ำกับ write-and-revise และ plan-work ไม่ติดตั้งทั้งคลัง เรื่องลงทุนและ TradingAgents คงรอตามคำสั่งผู้ใช้ ไม่ติดตั้งต่อจากงานนี้ Repokub อ่านรายการไม่ได้ จึงไม่อ้างว่าสกิลใหม่ค้นพบในเว็บนั้น ไม่มีการซื้อหรือสมัครบริการ
