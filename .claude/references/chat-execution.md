# ทำงานจากแชต — 5 พฤศจิกายน 2026

คำสั่งผู้ใช้ให้ทำงานจนเสร็จมีผลต่อการทำงานในขอบเขตที่อนุญาต ไม่ต้องรอให้สั่งซ้ำ ห้ามอ้างว่าเสร็จจากการเสนอเครื่องมือ การสร้าง ZIP หรือการอ่านหน้าเว็บเพียงอย่างเดียว

## เลือกความสามารถตามงาน

| คำขอ | สกิล | ข้อมูล/เครื่องมือที่ต้องมี |
| --- | --- | --- |
| แกะคลิปจากลิงก์ เทียบต้นฉบับ อธิบายฮุก | clip-breakdown | หน้าเว็บ ซับ ภาพ หรือวิดีโอที่เข้าถึงจริง |
| ดูฟุตเทจ คัดช็อต | watch | ไฟล์จริงและ runtime; มีแต่ URL เริ่ม clip-breakdown |
| เขียนบท แคปชัน ลำดับตัดต่อ | write-and-revise | เรื่องจริง/บรีฟที่มีอยู่ |
| ตัดต่อส่ง MP4 | ffmpeg-skill | ไฟล์จริง Python FFmpeg และสคริปต์ |
| ถอดเสียง ซับและเวลาคำ | thai-captions | เสียงจริงและ runtime; ซับแพลตฟอร์มใช้เป็นร่างได้แต่ต้องระบุแหล่ง |
| เลือกงาน/จัดแผน | plan-work | บริบทปัจจุบันและ Notion เมื่อจำเป็น |
| ตรวจงาน | quality-check | ชิ้นงานที่เปิดตรวจได้จริง |
| สรุปสถิติ/ต้นทุน | summarize-evidence | ตัวเลขจริง ไม่เติมยอดขาด |
| ส่งต่อแชต | cross-chat-handoff | สถานะและลิงก์ที่ตรวจแล้ว |

ใช้คำขอตามธรรมชาติ เช่น “แกะอันนี้”, “ตัดให้เลย”, “ทำซับ”, “สรุปไว้ทำต่อ” ไม่บังคับเรียกชื่อสกิล ทั้งชื่อไทบ้านคุณภาพและชื่อช่องบ่าวเบน อยากเป็นไทบ้านเป็นบริบทโครงการเดิม

## ตรวจแล้วทำต่อ

1. ใช้ข้อมูลและการอนุญาตที่มีแล้ว ไม่ถามซ้ำ ค้นไฟล์/ผลเดิมก่อนเริ่มใหม่
2. ค้นเครื่องมือที่เรียกได้จริงก่อนบอกว่าทำไม่ได้ การมี SKILL.md ไม่ยืนยันว่ามี Browser, Notion, FFmpeg หรือบัญชีพร้อมใช้
3. เลือก connector/API ที่ตรงงานก่อน Browser เว้นแต่ผู้ใช้ขอ Browser โดยตรง และอ่านสกิลบริการนั้นก่อนใช้
4. เปิดลิงก์สาธารณะตามปกติได้เมื่อเครื่องมือและนโยบายอนุญาต แยกเครือข่ายเสีย หน้าเว็บต้องรัน JavaScript และข้อจำกัดสิทธิ์ออกจากกัน ขอสิทธิ์ผ่านกลไกที่ระบบรองรับเมื่อจำเป็น ไม่ปิด proxy/TLS หรือดึง cookies
5. ถ้าทางหนึ่งล้มเหลว ใช้ทางอื่นที่เหมาะสมและอยู่ในสิทธิ์เดิม ไม่วนซ้ำผลเดิม ไม่ใช้ mirror หรือเปลี่ยนตัวตนเพื่อหลบข้อห้าม
6. หากขาดความสามารถภายนอก ค้นปลั๊กอินก่อนขอข้อมูลซ้ำ การเสนอปลั๊กอินไม่ใช่การติดตั้ง ผู้ใช้ต้องทำขั้นบัญชี/OAuth ด้วยตนเอง ทำงานอิสระส่วนอื่นต่อและบอกตัวขวางอย่างตรงไปตรงมา ห้ามอ้างว่าจะทำเบื้องหลังเอง
7. คำขอวิเคราะห์คลิปไม่ใช่งานผลิตชุดใหม่ จึงไม่ถามความยาว/พล็อตหรือรออนุมัติตัวอย่างก่อนวิเคราะห์ งานผลิตชุดใหม่ยังใช้กติกาตัวอย่างตามที่ผู้ใช้กำหนด
8. ส่งผลที่ตรวจได้และข้อจำกัดที่มีผลจริง ถ้ายังขาดส่วนสำคัญให้บอกว่างานเสร็จบางส่วน ไม่ถือว่าการอ่าน ASR เท่ากับฟังเสียงหรือดูทุกเฟรม

## ขอบเขตการใช้งานใน Chat

สกิลทั้งชุดอนุญาต implicit invocation และ CHAT/CODEX/HERMES ใน agents/openai.yaml การปรากฏในโฮสต์ยังขึ้นกับการเปิดปลั๊กอินและการโหลดรุ่นล่าสุด งานข้อความทำจากแชตได้ทันทีเมื่อข้อมูลพอ งานไฟล์/เสียง/วิดีโอใช้เครื่องมือประมวลผลที่มีจริง หากไม่มี runtime ให้ส่งเฉพาะผลที่ทำได้และระบุส่วนที่รอ ไม่ทำเครื่องหมายความสามารถทั้งหมดว่าทดสอบผ่าน

## แหล่งข้อมูลกลางและการเก็บบทเรียน

ใช้ [ข้อมูลกลางและทะเบียนทักษะ](central-knowledge.md) เริ่มงานที่ต้องอาศัยบริบทข้ามแชต แยกสถานะงานสดใน Notion ออกจากรุ่นคู่มือในปลั๊กอิน ใช้ผลอ่านเดียวกันร่วมกันและอ่านเฉพาะงานที่เกี่ยวข้อง เก็บบทเรียนพร้อมแหล่ง ผลทดลอง ข้อจำกัด และคำแก้เบนเมื่ออยู่ในขอบเขตการเก็บข้อมูลกลางที่สั่งไว้
