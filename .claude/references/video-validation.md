# แหล่งที่มาและผลทดสอบวิดีโอ 0.4.0

ตรวจเมื่อ 1 พฤศจิกายน 2026 ในสภาพแวดล้อมของงานนี้ ไม่ใช่การรับรอง runtime ของทุกแชต

## แหล่งที่มา

- [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) commit `1ce2c186bf1dba96132d87274eee46df4f537e0e` ใช้สคริปต์ references และ templates ภายใต้ MIT พร้อมใบอนุญาตใน `skills/ffmpeg-skill/LICENSE` เก็บคู่มือเดิมเป็น UPSTREAM-SKILL.md และเขียนหน้าสกิลภาษาไทยให้ตรงโครงการ
- ปรับ `scripts/silence.py` เฉพาะการรวมช่วง keep ที่ซ้อนกัน เพื่อให้ระยะเวลารายงานและ timemap ตรงกับ union ที่เรนเดอร์ ไม่รายงานความยาวมากกว่าต้นฉบับเมื่อ margin ซ้อนกัน ใช้ `--margin 0` สำหรับรอบตัด filler สั้นและตรวจ padding จากเวลาคำจริง
- [SYSTRAN/faster-whisper](https://github.com/SYSTRAN/faster-whisper) เป็น dependency สำหรับ ASR ในเครื่อง ใช้ 1.2.1 พร้อม PyAV 16.1.0 ที่ทดสอบเข้ากันแล้ว ไม่บรรจุแพ็กเกจหรือโมเดลลงปลั๊กอิน
- [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp) 5.4.0 เป็น dependency สำหรับตัดคำเพื่อจัดบรรทัด สคริปต์เชื่อมและส่งออก SRT/ASS ใน `thai-captions` เขียนเพิ่มสำหรับชุดนี้

contact sheet ตรวจภาพตัวอย่างเท่านั้น ไม่ได้ฟังเสียงหรือดูทุกเฟรม การตรวจ custom preset ไม่มีข้อ fail แต่มีคำเตือนเรื่องไฟล์ทดสอบเสียง 16 kHz และไม่มี subtitle stream แยก เนื่องจากซับเผาบนภาพ โดยส่ง SRT แยกได้ ไฟล์สังเคราะห์ไม่ใช่งานพร้อมโพสต์ของเบน

## ส่วนที่ยังไม่ยืนยัน

- ความแม่นยำกับเสียงเบน สำเนียงอีสาน เสียงรบกวน และชื่อสินค้า ต้องทดสอบกับฟุตเทจจริง
- ไม่มี face detection, การจับคนพูดหลายคน หรือการตัดประโยคซ้ำเชิงความหมายอัตโนมัติในตัวเชื่อมนี้
- มี plain/fade/pop สำหรับ ASS และ motion ตามสคริปต์ ไม่อ้างว่ามีสไตล์เท่าชุด PAN X BOXY และไม่ได้ใช้ไฟล์ของผู้ขายนั้น
- เวลาคำจาก ASR เป็นค่าประมาณ ต้องตรวจจุดตัด ไม่ถือว่าความเงียบเท่ากับคำเอ่อ/อ่า
- ใช้ Python 3.10+, FFmpeg/FFprobe 6.1+ และฟอนต์ไทยที่ติดตั้ง ในรอบทดสอบใช้ FFmpeg 7.1.5, Python 3.12 และ Noto Sans Thai โมเดลหรือ dependencies ไม่ได้ติดตั้งข้ามทุกแชตอัตโนมัติ ดู [การเปิด runtime](video-runtime-setup.md)


## ตรวจเพิ่มสำหรับ iPhone — 0.4.1

เปิดตรวจสกิลรุ่น 0.4.0 ทั้งเส้นทางตัดต่อและซับไทยผ่าน skill reader และเทียบเนื้อหาสคริปต์ transcribe_thai.py, requirements.txt และ probe.py ในเครื่องกับ source ที่บันทึกในปลั๊กอินก่อนรันทดสอบ รุ่นและแพ็กเกจยังเป็นชุดเดิม ไม่เพิ่มสกิล

ตรวจพบ Python/FFmpeg, dependencies และโมเดล base ที่เข้าถึงได้จริงในรอบนี้ แล้วรันตัวถอดเสียงด้วย --local-files-only บนไฟล์เสียงไทยสาธารณะชุดเดิม จากนั้นตรวจไฟล์ซับและส่งเข้า caption.py เพื่อทดสอบเส้นทาง SRT/ASS -> MP4 ผลการรันและการตรวจภาพเพิ่มจะบันทึกตามที่ตรวจได้ ไม่ใช้ข้อความส่งต่องานแทนหลักฐาน runtime

แก้คำแนะนำส่งมอบให้แยก clean MP4, preview ที่เผาซับ และ SRT ที่ตรงกัน และเพิ่มคู่มือ [iPhone](iphone-quickstart.md) โดยตรวจ [เอกสาร CapCut ทางการ](https://www.capcut.com/help/how-to-import-subtitles): การนำเข้า SRT ใช้ Desktop/Web ไม่ใช่แอปมือถือ ยังไม่ได้เข้าถึงหรือทดสอบ CapCut บน iPhone ของเบน ไม่มีฟุตเทจจริงของเบน และไม่มีคะแนนความแม่นยำเสียงเบน/อีสาน


ผลการตรวจเพิ่มรอบนี้: สคริปต์ runtime ในเครื่องตรงกับ source release 0.4.0 ที่ตรวจแล้วครบ 61 ไฟล์ รัน ASR base แบบ local-files-only จากไฟล์เสียงไทยตัวอย่างได้ 21 รายการคำจากโมเดล ตรวจ SRT เทียบข้อความและเวลาที่ส่งออกแล้วตรงกัน จากนั้น dry-run และเรนเดอร์ ASS ลง MP4 ใหม่สำเร็จที่ 360×640, 25 fps, 3.44 วินาที, H.264/AAC 48 kHz ตรวจ custom preset พบ 0 ข้อ fail และ 1 คำเตือนว่าไม่มี subtitle stream แยก เพราะรอบนี้เผาซับลงภาพและส่ง SRT เป็นไฟล์แยก ดูภาพ contact sheet ใหม่ 2 เฟรมแล้วเห็นตัวอักษรไทยอยู่ในกรอบ ไม่ได้ฟังเสียงหรือดูทุกเฟรม และไม่ให้คะแนนความแม่นยำภาษาไทยจากการรันสำเร็จ
