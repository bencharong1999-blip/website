# คลังสกิลและเครื่องมือสำหรับอนาคต

บันทึกตามคำขอเบน: ติดตั้งเฉพาะที่เพิ่มประโยชน์ให้งานปัจจุบัน เก็บตัวที่ยังไม่จำเป็นพร้อมลิงก์และเหตุผล การมีชื่อในหน้านี้ไม่เท่ากับติดตั้งหรือทดสอบ ต้องตรวจ source/ใบอนุญาต/requirements รุ่นปัจจุบันอีกครั้งเมื่อจะใช้

หน้าแผนและสถานะหลักยังเป็น [Notion เดิม](https://app.notion.com/p/40b52d4a2f43818d8e8ccf778995100f) ไม่สร้างศูนย์งานใหม่

## ใช้ตอนนี้

- `watch`: เพิ่มในปลั๊กอินเดิมสำหรับดูภาพพร้อมเวลาและคัดช็อตจากไฟล์ของเบน ทางเรียก local ไม่มี cloud/ASR เพิ่ม
- งานเสียง: ใช้ `audio.py` ใน `ffmpeg-skill` ที่มีอยู่แล้ว พร้อม [คู่มือปรับเสียง](audio-cleanup.md) ไม่เพิ่มสกิลซ้ำ
- แผน เขียน สรุป ตรวจงาน ส่งต่องาน ตัดต่อ และซับไทย: คง 7 สกิลเดิม

## ซ้ำกับของเดิม — เก็บลิงก์อ้างอิง ไม่ติดตั้งเพิ่ม

คลัง [Thai Claude Skills](https://github.com/PiNocPie/thai-claude-skills/tree/94b8377c142680c91873995c444c6f42b87c0f73) มี README, LICENSE และ CREDITS ที่ตรวจแล้ว มีหลายตัวซ้ำกับหน้าที่เดิม เช่น hook-generator-th, caption-writer-th, video-script-th, content-calendar-th, task-prioritize-th และ weekly-review-th จึงไม่ติดตั้งทั้งหมดและไม่รับรองว่าได้ตรวจทุกสกิล โครง hook ที่เปิดอ่านเป็นคำแนะนำข้อความ ไม่ใช่ระบบตัดต่อที่รันได้

เก็บรายชื่อและลิงก์ของคลังนี้ที่ `thai-skills-catalog.json` โดยระบุสถานะยังไม่ประเมินเป็นรายตัว ไม่เปิดเป็น active skill ทุกตัว

## สถานะ Repokub

[Repokub](https://repokub.com/) อ่านหน้าแนะนำ เงื่อนไข และหน้าความปลอดภัยได้ แต่รายการในคลังยังไม่แสดงผ่านเครื่องมืออ่านหน้าเว็บ และการเรียกตรงได้ HTTP 403 จึงยังไม่ยืนยันว่าสกิลใดในรายการนี้อยู่ใน Repokub การคัด Watch และ Thai Claude Skills รอบนี้มาจาก GitHub โดยตรง ไม่มีการซื้อ Gold/Platinum หรือหลบข้อจำกัดการเข้าถึง

การเก็บคลังไม่สร้างระบบติดตามเบื้องหลัง และไม่ทำให้ไฟล์งานหรือ runtime ติดตามทุกแชตอัตโนมัติ
