# ปรับเสียงฟุตเทจกลางแจ้งด้วยสกิลเดิม

ใช้ `ffmpeg-skill` และสคริปต์ `audio.py` ที่มีอยู่ ไม่ต้องติดตั้งโปรแกรมหรือโมเดลใหม่ ตัวเลือกต่อไปนี้ตรวจจาก source release 0.4.2 และทดลองกับเสียงสังเคราะห์แล้ว ยังไม่ใช่หลักฐานว่าปรับเสียงเบนได้ดี

1. ตรวจว่ามีเสียงจริงและเลือก audio stream ที่ถูก เก็บต้นฉบับ ฟังช่วงที่มีทั้งคำพูดและเสียงรบกวนก่อนกำหนดวิธี
2. ทดลองช่วงสั้นก่อน ถ้าเสียงดีอยู่แล้วไม่ต้อง denoise เริ่ม `--voice light` สำหรับตัดเสียงต่ำและปรับระดับเบา ๆ; `--voice medium` เพิ่ม de-esser/FFT denoise; ใช้ strong เมื่อมีหลักฐานว่าจำเป็น ไม่รับรองว่าลมแรงหรือคำพูดที่หายไปกู้คืนได้

```sh
python3 <ffmpeg-skill-dir>/scripts/audio.py INPUT.mp4 --voice light --dry-run --json -o C001_audio_preview.mp4
python3 <ffmpeg-skill-dir>/scripts/audio.py INPUT.mp4 --voice light --json -o C001_audio_preview.mp4
```

3. ฟัง A/B ระดับเสียงใกล้กัน ตรวจคำต้น/ท้าย เสียงซ่า เสียงแตก และบรรยากาศที่จำเป็น ถ้าไม่มีเครื่องมือฟัง ให้ระบุว่ายังไม่ได้ตรวจคุณภาพการฟัง แล้วส่งตัวอย่างให้เบนตรวจบน iPhone ไม่ตีความ `verified: true` จาก probe ว่าเสียงฟังดีแล้ว
4. เส้นทางนี้ไม่ตัดเวลา ภาพเป็น stream copy ตามความสามารถของ codec/container เดิม ตรวจเวลาและ stream ของไฟล์ผลจริง ถ้าจะเปลี่ยนเวลาให้ทำก่อนสร้างซับใหม่
5. ส่งต้นฉบับกับไฟล์ตัวอย่างที่ตั้งชื่อแยกกันให้เทียบ ใช้ `loudness.py` เพิ่มเฉพาะเมื่อได้ตรวจระดับเป้าหมาย ไม่เติมเพลงหรือใช้ gate แรงจนกินคำพูด

ไม่มีการใช้บริการเสียเงิน ไม่มี API key และยังไม่มีการประเมินเสียงลม รถ หรือสำเนียงอีสานของเบน
