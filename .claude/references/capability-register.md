# ทะเบียนความสามารถส่วนตัว — บันทึกเฉพาะสิ่งที่ตรวจจริง

วันที่ 4 พฤศจิกายน 2026 ใช้ร่วมกับสถานะล่าสุดและไฟล์ใน Notion ไม่ถือว่าทุก runtime มีของติดตั้งแล้ว

| ความสามารถ | หลักฐาน/ระดับ | สิ่งที่ใช้ซ้ำและข้อจำกัด |
| --- | --- | --- |
| ตรวจวิดีโอและไฟล์ซ้ำ | ใช้กับงานจริง: 84 ไฟล์ ตรวจ FFprobe และ SHA-256; 12 สำเนาตรงกัน เหลือ 72 ไฟล์ | ใช้ทะเบียน/แฮชซ้ำ ลบเฉพาะที่ผู้ใช้สั่งและยืนยันเหมือนจริง ไม่ใช้ชื่อหรือขนาดอย่างเดียว |
| คัดภาพพร้อมเวลา | ใช้กับงานจริง: Watch สูงสุด 4 ภาพต่อไฟล์ 72 คลิป | ภาพตรวจไม่ใช่การชมทุกเฟรมหรือรู้คำพูด |
| สร้างร่าง MP4 แนวตั้ง | ใช้กับงานจริง: สองร่าง 40/36 วินาที 1080×1920 60 fps มี Drive readback | เก็บร่างนี้เป็นประวัติ ชุดเปิดตัวใหม่ต้องถาม/ใช้บรีฟ 2–3 นาที ไม่ข้ามตัวอย่างก่อนผลิต |
| ถอดเสียงไทย | ทดลอง/ใช้จริง: faster-whisper small + PyThaiNLP | ช่วงเงียบยาวให้ผลไม่นิ่ง อ่านกลับแยกประโยคช่วยได้ แต่ไม่ใช้ ASR รับรองเสียงเหมือนหรือทุกคำถูก |
| เสียงต้นแบบเบน | ใช้สร้างร่างจริง: F5-TTS-TH-V2 16 steps speed .92 ผสมเสียงจริง | สร้างช้าใน CPU 2 คอร์ ลดงานซ้ำ เก็บ cache; CPU threads 2 และ Linear int8 เป็นการทดลองที่ใช้ร่างนี้แล้ว เสียงอัดเองยังเป็นตัวเลือกหลัก |
| ส่งตัวอย่างก่อนงานใหญ่ | กติกาใหม่ บันทึกแล้ว | ต้องมีภาพ/บท/พล็อตให้ตรวจและรอคำแก้ก่อนผลิตเต็ม ยังไม่อ้างว่า workflow ใหม่นี้ลดโทเค็นกี่เปอร์เซ็นต์ |

แบบบันทึกหลังงาน: งาน/เวอร์ชัน → สิ่งที่ทำและตรวจ → ไฟล์/ลิงก์ → ปัญหาและวิธีแก้ → คำแก้ของเบน → สิ่งที่จะใช้ซ้ำ → ส่วนที่ยังไม่ทดสอบ

## Remotion motion graphics — 4 พฤศจิกายน 2026

ติดตั้ง Remotion4.0.540 และเรนเดอร์ข้อความไทยเคลื่อนไหว 5วินาที H.264 1080×1920 30fps ผ่าน ถอดรหัสเต็มและตรวจภาพหนึ่งจุดแล้ว ตัวอย่างไม่มีเสียง ไม่ใช่การทดสอบวิดีโอยาวหรือซิงก์ซับกับเสียง บันทึก source/config/package-lock และฟอนต์พร้อมสิทธิ์ใน scripts/remotion-hook; dependencies ต้องติดตั้งใน runtime ที่รองรับ Chromium และมีพื้นที่เพียงพอ

อ้างอิง Reel2551499671992769 ดาวน์โหลดวิดีโอสาธารณะ25.466วินาทีและตรวจภาพ13จุด เห็น AI Edit Pro พร้อมคำโฆษณาตัดต่อ/ซับ/โมชั่น/โพสต์อัตโนมัติ ยังไม่ได้ฟังเต็มและยังไม่ได้ไฟล์สกิลต้นฉบับ ไม่ยืนยันว่าเจ้าของใช้ Remotion หรือสกิลใด ความสามารถนี้เลือกจากเอกสารทางการ Remotion แยกจากตัวอย่างดังกล่าว

## แกะคลิปจากหน้าเว็บสาธารณะ — 5 พฤศจิกายน 2026
