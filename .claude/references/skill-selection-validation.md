# ผลตรวจการเพิ่มสกิล — 0.5.0

ตรวจ source รุ่น 0.4.2 ของปลั๊กอินเดิม ก่อนเพิ่ม Watch จาก commit `03ceb42f7fa2c4439aca01752118044baabffb8f` และทางเรียก `review_local.py` ที่เขียนเพิ่ม สคริปต์ Python ของ Watch ที่นำเข้าตรวจ SHA-256 เทียบกับ source ที่ดึงจาก GitHub ภายใต้ MIT เก็บ copyright notice ไว้ใน LICENSE

## สิ่งที่รันจริง

- สร้างวิดีโอสังเคราะห์ 6 วินาที 320×568, H.264/AAC มี test pattern เคลื่อนไหว โทนเสียง และ pink noise ไม่ใช่คลิปหรือเสียงเบน
- รัน Watch local/no-whisper: รอบแรกได้ 6 ภาพรวม cue ที่ระบุ; รอบทางเรียกใหม่จำกัด 6 ภาพในช่วง 1–5 วินาที ได้รายงานและภาพจริงครบ ตรวจว่าพาธมีอยู่และโควตาภาพไม่เกินกำหนด
- เปิดดูภาพผล 2 ภาพจริง เห็นภาพ test pattern กับเวลาบนภาพ 1 และ 4 วินาที ไม่อ้างว่าดูทุกเฟรม
- ทางเรียกใหม่ปฏิเสธ URL และจำนวนภาพ 100 ก่อนทำงาน เป็นเส้นทาง local เท่านั้น
- SHA-256 ของไฟล์ต้นฉบับก่อนและหลัง review ตรงกัน
- เทียบสคริปต์ audio/scenes/report และ 6 โมดูลช่วยที่ใช้ทดสอบในเครื่องกับ source ของปลั๊กอินปัจจุบันแล้วตรงกัน จากนั้นรัน audio.py --voice medium --json ได้ MP4 6 วินาทีจริง ภาพ decoded frame hash ตรงกับต้นฉบับและยังมีเสียง
- ตรวจ 14 เงื่อนไขการทำงานข้างต้นผ่าน เก็บหลักฐานรอบนี้ใน `/workspace/scratch/thaiban-watch-validation/validation.json` พาธนี้เป็นของ runtime รอบทดสอบ ไม่รับรองว่าตามไปทุกแชต

## ข้อจำกัด

ไม่ได้ฟังเพื่อให้คะแนนคุณภาพเสียง ไม่ให้คะแนนลดเสียงลมหรือความแม่นยำภาษาไทย/อีสาน ไม่มีฟุตเทจเบน ไม่ได้ทดสอบ URL/yt-dlp, cloud, WhisperX, Mac, face tracking หรือการควบคุม CapCut การทดสอบไม่ส่งไฟล์ไปผู้ให้บริการ AI ไม่ใช้ API key และไม่เผยแพร่คลิป T004 และคลิปจริงยังรอฟุตเทจจากเบน

การบันทึกรุ่นปลั๊กอินต้องตรวจ read-back อีกครั้ง แยกจากผลรันใน runtime ก่อนเผยแพร่รุ่นนี้ การโหลดสกิลในแชตใหม่อาจต้องเปิดปลั๊กอินใหม่และตรวจเครื่องมือ/ไฟล์จริง
