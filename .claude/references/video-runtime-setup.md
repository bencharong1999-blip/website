# เปิดใช้สคริปต์ในสภาพแวดล้อมของแชต

ไฟล์แนบในปลั๊กอินไม่ได้ยืนยันว่าอยู่ใน filesystem ของทุกแชตแล้ว ใช้ตำแหน่งสกิลที่ host ระบุเมื่อมีอยู่จริง ไม่ใช้ `/workspace/...` จากงานเก่าโดยไม่ตรวจ

หากเปิดคำแนะนำสกิลได้แต่ยังไม่มีสคริปต์ในเครื่อง:

1. เมื่อ Plugin Creator source tools พร้อมใช้ ให้ตรวจ `get_plugin_files` รุ่นปัจจุบันของปลั๊กอิน ID `plugins_6ae6f50b063081918275e04d86a7ca0c` และอ่านสคริปต์/โมดูลที่ต้องใช้จากพาธที่เครื่องมือคืนมา เก็บโครงไฟล์เดิม ถ้าบางไฟล์ใหญ่หรือ source reader อ่านไม่ได้จึงใช้ `get_owned_plugin_archive` โดยไม่ระบุ release เก่า
2. ดาวน์โหลดจาก URL ที่เครื่องมือคืนมาลงพื้นที่ชั่วคราวที่เขียนได้ ตรวจชื่อรายการและปฏิเสธ symlink หรือพาธออกนอกโฟลเดอร์ก่อนแตกไฟล์ เก็บหนึ่งโฟลเดอร์ปลั๊กอินตามที่ archive ให้มา
3. ใช้ `skills/ffmpeg-skill/scripts/` และ `skills/thai-captions/scripts/` ภายในโฟลเดอร์นั้น ตรวจ Python/FFmpeg ก่อน ส่วนถอดเสียงใช้ venv แยกตาม SKILL.md และ cache โมเดลในพื้นที่เขียนได้
4. หากไม่มีเครื่องมือดาวน์โหลด ไม่มีสภาพแวดล้อมรันคำสั่ง หรือสิทธิ์ไม่พอ ให้รายงานส่วนที่ขาด การอ่านคำแนะนำอย่างเดียวไม่ใช่การติดตั้งหรือการตัดต่อสำเร็จ

อย่าอัปโหลดแพ็กเกจส่วนตัวหรือฟุตเทจไปเว็บสาธารณะเพื่อแก้ปัญหาการเข้าถึง runtime และไม่ต้องสร้างปลั๊กอินใหม่เพื่อโหลดสคริปต์เดิม


## Watch — เพิ่มใน 0.5.0

เก็บ `skills/watch/scripts/` ทุกโมดูลไว้ด้วยกัน ทางเรียกหลักคือ `review_local.py INPUT --out-dir DIR --max-frames 12` ใช้ Python standard library + FFmpeg/FFprobe สำหรับไฟล์ local ที่ทดสอบแล้ว ไม่ต้องติดตั้ง WhisperX หรือเรียก setup.py ของ upstream เพื่อใช้เส้นทางนี้ การเข้าถึง URL/yt-dlp และ cloud เป็นอีกเส้นทางที่ยังไม่ทดสอบ ไม่เปิดอัตโนมัติ ใช้ `thai-captions` เดิมสำหรับเสียงไทย
