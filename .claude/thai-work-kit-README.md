# ชุดสกิลทำงาน — สำหรับไทบ้านคุณภาพ

เวอร์ชัน 0.7.2 มี 9 สกิลตาม [หน้าแผนหลักใน Notion](https://app.notion.com/p/40b52d4a2f43818d8e8ccf778995100f) โฟกัสคลิปชีวิตจริง การผลิตด้วย iPhone/CapCut และการติดตามผลกับ Affiliate

| สกิล | งานที่ใช้ | ตัวอย่างคำสั่ง |
| --- | --- | --- |
| `plan-work` | เลือกงานวันนี้และติดตามงานผลิต | ดูแผนไทบ้านคุณภาพแล้วเลือกงานวันนี้ไม่เกิน 3 งานที่พร้อมทำ |
| `write-and-revise` | สคริปต์ คำพากย์ รายการช็อต แคปชัน และลำดับตัดต่อ | ทำสคริปต์คลิปจากเรื่องจริงนี้ พร้อมช็อตและลำดับตัดต่อ CapCut |
| `summarize-evidence` | วิเคราะห์ผลคลิป ต้นทุน และรายได้จริง | สรุปผลสัปดาห์นี้และเสนอสิ่งที่ควรทดลองต่อ โดยใช้เฉพาะตัวเลขที่มี |
| `quality-check` | ตรวจคลิปและข้อมูลก่อนโพสต์ | ตรวจคลิปนี้ บอกจุดที่ต้องแก้และส่วนที่ยังตรวจไม่ได้ |
| `cross-chat-handoff` | ส่งต่องานพร้อมลิงก์ Notion รหัสงาน และไฟล์ | สรุปงานไทบ้านคุณภาพไว้เปิดแชตใหม่ พร้อมงานถัดไป |
| `ffmpeg-skill` | ลงมือตัดต่อ MP4 ใส่ B-roll แบ่งจอ motion และปรับเสียง | ตัดต่อคลิปนี้ให้กระชับ ใส่ภาพแทรก และส่ง MP4 |
| `thai-captions` | ถอดเสียง ทำซับไทย SRT/ASS และเวลาคำ | ทำซับไทยจากเสียงจริง จัดบรรทัด และใส่ซับแบบ pop |

| `watch` | ดูภาพพร้อมเวลาและคัดช็อตจากไฟล์จริงในเครื่อง | ดูฟุตเทจนี้แล้วคัดช็อตที่ใช้เล่าเรื่อง พร้อมจุดที่ต้องถ่ายเพิ่ม |

อ่าน [บริบทและวิธีใช้หน้าแผน](references/thaiban-project.md) และ [เหตุผลการคัดเลือก](references/selection-notes.md)

## ขอบเขตชุดนี้

ตัด `clarify-work`, `poster-brief` และ `research-recent` ออกจากแพ็กเกจ เพื่อให้ชุดนี้ตรงกับงานปัจจุบัน การถามข้อมูลที่จำเป็นยังทำได้ในแต่ละงาน ส่วนการค้นเงื่อนไข Affiliate ล่าสุดทำเมื่อเกี่ยวข้องและมีเครื่องมือ ไม่เพิ่มภาระค้นกระแสหรือทำโปสเตอร์ประจำ

## ช่วยเลือกทางก่อนเพิ่มงาน

สกิล `plan-work` มี [กรอบตัดสินใจแบบย่อ](skills/plan-work/references/decision-review.md) สำหรับเทียบช่องทาง อุปกรณ์ หรือการทดลองคอนเทนต์ โดยดูประโยชน์ เงิน คนดู กำลังทำงาน และความน่าเชื่อถือ เช่น “ช่วยเทียบโฟกัส TikTok ก่อนกับทำสามช่องพร้อมกัน” ใช้เมื่อมีทางเลือกสำคัญ กรอบนี้อยู่ในสกิลเดิม ไม่เพิ่มสกิลประชุมแยก

## เริ่มใช้จาก iPhone

อ่าน [คู่มือส่งฟุตเทจ บรีฟสั้น และรับไฟล์](references/iphone-quickstart.md) ก่อนเริ่มชุดแรก ดู preview บนมือถือแล้วส่งคำแก้กลับมาได้ หากต้องแก้ข้อความเองให้ใช้ clean MP4 แทนฉบับที่เผาซับแล้ว เอกสาร CapCut ระบุว่านำเข้า SRT โดยตรงได้บน Desktop/Web ไม่ใช่แอปมือถือ จึงไม่ต้องติดอยู่กับเมนูนำเข้าที่ไม่มีบน iPhone

## ใช้ข้ามแชต

เลือกปลั๊กอิน **ชุดสกิลทำงาน** ในแชตใหม่ และบอกว่า “ทำงานไทบ้านคุณภาพต่อจากหน้าแผนหลัก” สกิลมีลิงก์หน้าเดิมเป็นจุดเริ่ม แต่แชตนั้นยังต้องมีการเชื่อม Notion และสิทธิ์เข้าถึง หากเข้าไม่ได้ ให้นำบันทึกส่งต่อและไฟล์ที่จำเป็นมาด้วย

ประวัติแชตและไฟล์แนบไม่ติดตามไปอัตโนมัติ การร่างสคริปต์ไม่ใช่วิดีโอที่ตัดเสร็จ การส่งออก MP4 หรือควบคุม CapCut ต้องตรวจเครื่องมือและทดลองจริงก่อนยืนยัน การตรวจคลิปไม่ใช่การโพสต์ ผู้ใช้เป็นผู้ตรวจและเผยแพร่ เว้นแต่มีคำขอและเครื่องมือที่รองรับการทำแทน

เมื่อสั่งอัปเดต Notion ให้แก้เฉพาะงานในหน้าเดิมตามสถานะที่ตรวจได้ ไม่สร้างแผนกลางหรือฐานข้อมูลซ้ำ และไม่ถือการมีสกิลเป็นระบบทำงานเบื้องหลัง

โทนแดง–ดำเป็นหน้าตาปลั๊กอิน ไม่ได้เปลี่ยนโลโก้หรือภาพแบรนด์ไทบ้านคุณภาพที่เลือกไว้แล้ว

## ส่วนประมวลผลวิดีโอที่เพิ่ม

รวมสคริปต์จาก [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) ภายใต้ MIT และตัวเชื่อมถอดเสียงภาษาไทยที่เขียนเพิ่ม ใช้ [faster-whisper](https://github.com/SYSTRAN/faster-whisper) กับ [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp) มีไฟล์ติดตั้งส่วนเสริมใน venv แยก จึงไม่ต้องซื้อ PAN X BOXY เพื่อใช้แนวทางนี้

ต้องมีสภาพแวดล้อมรันคำสั่ง Python/FFmpeg; การเปิดจากมือถือยังต้องให้สภาพแวดล้อมนั้นทำงานแทน การมีปลั๊กอินอย่างเดียวไม่ยืนยันว่าทุกแชตติดตั้ง dependencies หรือโมเดลแล้ว โมเดลไม่รวมในแพ็กเกจและอาจดาวน์โหลดครั้งแรก เสียงประมวลผลในเครื่อง

ซับมี plain, fade และ pop; motion กราฟิกเลือกตามสคริปต์ที่มี ไม่มีการรับประกันจำนวนสไตล์เท่าระบบของผู้ขายอื่น ไม่มี face detection หรือการตัดประโยคซ้ำเชิงความหมายอัตโนมัติ คำเอ่อ/อ่าใช้เวลาคำจริงพร้อมรายการคำเฉพาะและตรวจจุดตัดก่อนใช้

อ่าน [แหล่งที่มาและผลทดสอบ](references/video-validation.md) ก่อนอ้างความสามารถที่ทดสอบแล้ว การอ่านไฟล์หรือการตรวจผ่าน ffprobe ไม่เท่ากับตรวจเสียงและภาพทุกเฟรม


## เพิ่มการตรวจฟุตเทจและเก็บสกิลสำรอง — 0.5.0

เพิ่ม Watch จาก bradautomates/claude-video พร้อม MIT และสคริปต์จริง ทางเรียก `review_local.py` รับไฟล์ในเครื่องและปิด cloud/ASR fallback โดยชัดเจน ไม่ต้องใช้ API key หรือ WhisperX เพิ่ม หากต้องฟัง/ถอดเสียงให้ใช้ thai-captions เดิม การดูภาพตัวอย่างไม่เท่ากับดูทุกเฟรมหรือฟังทั้งคลิป

ดู [คู่มือปรับเสียงที่มีอยู่แล้ว](references/audio-cleanup.md), [คลังสำหรับอนาคตและเหตุผลที่พักไว้](references/future-skill-library.md) และ [ผลตรวจรอบนี้](references/skill-selection-validation.md) Repokub ยังไม่แสดงรายการผ่านเครื่องมืออ่านเว็บ รอบนี้จึงตรวจต้นทาง GitHub โดยตรง ไม่อ้างว่าสกิลที่เลือกพบในคลัง Repokub

## เรียกใช้จากแชต — 0.7.0

สกิลเดิมทั้ง 8 และ `clip-breakdown` ใหม่ เปิด implicit invocation และรองรับ CHAT/CODEX/HERMES เรียกจากคำขอตามธรรมชาติได้เมื่อโฮสต์โหลดปลั๊กอินรุ่นนี้ ดู [ตารางเลือกสกิลและเครื่องมือ](references/chat-execution.md) และ [บทเรียนคลิปบ้านสามชั้น](references/clip-storytelling-case.md) ไม่ต้องรอ Notion สำหรับงานที่มีข้อมูลในแชตครบแล้ว งานประมวลผลยังต้องมี runtime/ไฟล์จริงและการเชื่อมบัญชีที่เกี่ยวข้อง การเปิด policy ไม่สร้างเครื่องมือขึ้นมาเอง
